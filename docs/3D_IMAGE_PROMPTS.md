# 푸른행성 조사본부 3D 지구 이미지와 제작 프롬프트

1장 지구 관찰에만 조작 가능한 3D 지구를 사용해. 메인 다음 자연 속 스테이지 선택 화면은 픽셀아트 2.5D이고, 장소 안의 학습·실험·조사·결과 화면은 2D야. 이 문서는 제작할 기본 이미지, 바로 쓸 수 있는 프롬프트, 이미지 없이 구현할 부분을 정리한 제작 준비안이야. 아직 이미지나 3D 모델을 생성한 상태는 아니야.

# 3D 적용 범위

| 화면 | 표현 방식 | 결정 |
|---|---|---|
| 메인 | 기존 일러스트 배경과 2D 캐릭터 | 2D |
| 자연 속 스테이지 선택 | 사선으로 내려다보는 픽셀아트 맵과 걷는 캐릭터 | 2.5D 전용 |
| 1장 첫 화면의 지구 관찰 패널 | 손으로 돌려 보는 구체, 대기 관찰, 지표 스캔 | 유일한 실시간 3D |
| 나머지 학습 화면과 최종 미션·엔딩 | 일러스트, 2D 애니메이션, CSS UI | 2D |

지구의 구체는 코드로 만들고 표면 이미지를 입히는 방식을 추천해. 사진 한 장을 3D 변환 서비스에 넣어 구체를 복원할 필요가 없어. 실제 대륙과 바다 위치를 유지하기도 더 쉬워.

# 기본 이미지 목록

아래 파일명과 크기는 앞으로 제작할 때 사용할 제안 규격이야.

| ID | 기본 이미지 | 규격 | 우선순위와 제작 방법 |
|---|---|---|---|
| E01 | 지구 표면 텍스처 | 2048×1024, 2:1, 불투명 PNG 또는 WebP | 필수. 검증된 전 지구 지도를 바탕으로 제작 |
| E02 | 육지·바다 판정 마스크 | E01과 동일 좌표·크기의 무손실 PNG | 필수 데이터 이미지. 검증된 해안선 자료로 제작하며 AI 생성 금지 |
| E03 | 얇은 구름 레이어 | 1024×512, 2:1, 투명 PNG | 선택. 관찰 장식용이며 지표 스캔 때 숨김 |
| E04 | 지구 외형 기준 이미지 | 1024×1024, 투명 PNG | 선택. 분위기 합의용 한 장이며 텍스처로 사용하지 않음 |
| E05 | 2D 대체용 지구 이미지 | 동일 지구의 서로 다른 방향 4장, 각 1024×1024 | 3D 오류 대비. 완성한 동일 지구에서 렌더해 제작 |

최소 제작은 E01과 E02부터 시작해. E03·E04는 없어도 학습 기능을 만들 수 있어. E05는 3D 지구가 완성된 뒤 추출하면 돼.

구체, 대기 표시, 관찰 핀, 선택 테두리, 스캔 효과에는 별도 생성 이미지가 필요하지 않아. 대기 표시와 구름은 서로 다른 요소로 구현해.

# E01 지구 표면 텍스처 프롬프트

**입력:** 검증된 2:1 전 지구 지도. 구체를 촬영한 사진이나 화면 샘플을 입력하지 않아.

**복사해서 쓰는 이미지 편집 프롬프트**

참조로 제공한 전 지구 정거원통도법 지도를 초등학교 3학년 과학 탐구 게임용 지구 표면 텍스처로 다듬어 줘. 출력은 정확히 가로 2048, 세로 1024픽셀의 2:1 평면 지도야. 원본의 투영법, 경위도 대응, 대륙과 섬의 위치, 해안선 윤곽, 남극과 북극의 위치를 그대로 유지해. 새로운 땅이나 섬을 추가하거나 지형을 이동하지 마. 바다는 맑고 깊은 파랑, 육지는 자연스러운 초록과 황갈색으로 표현하고 작은 화면에서도 경계가 구분되게 해. 구름, 대기광, 낮과 밤의 그림자, 광택, 조명 방향, 글자, 국경선, 지도 기호, 위경도 격자를 넣지 마. 좌우 끝이 구체에서 자연스럽게 이어지는 텍스처로 만들고, 지구 구체나 원근법 장면으로 그리지 마. 게임의 기존 청록·파랑 계열 배경과 어울리게 색감만 절제해서 다듬어 줘.

**확인:** 원본과 겹쳐 해안선과 좌표를 비교해. AI 편집이 위치를 바꾸면 그 결과는 학습용으로 쓰지 않고 검증된 원본 텍스처를 사용해. 색상만으로 육지·바다를 판정하지 않아.

# E02 육지와 바다 판정 마스크 제작 지시

이 항목은 이미지 생성 프롬프트가 아니라 개발·데이터 제작 지시야.

E01과 동일한 경위도 좌표, 원점, 가로세로 비율을 사용하는 2048×1024 판정 마스크를 제작해. 검증된 해안선 자료로 육지는 255, 바다는 0으로 저장하고 보간으로 중간 판정값을 만들지 마. 남극 대륙의 얼음과 바다 위 해빙을 흰색이라는 이유로 같은 지형으로 분류하지 마. 호수와 강이 바다로 잘못 판정되지 않도록 표본 위치를 검수해. 육지의 물·해안 경계 등 이분법으로 다루기 어려운 위치는 MVP의 스캔 표본 후보에서 제외하고 별도 메타데이터로 관리해. 구체 회전 후에도 화면의 지점, UV 좌표, 판정값이 일치하는지 검증해.

학생이 찍은 몇 개 지점의 개수만으로 지구 전체 육지·바다 면적을 확정하지 않아. 직접 모은 표본과 전체 지표 자료를 구분해서 비교하도록 설계해.

# E03 구름 레이어 프롬프트

**복사해서 쓰는 이미지 생성 프롬프트**

지구 구체 위에 얹을 교육용 구름 전용 텍스처를 만들어 줘. 정확히 1024×512픽셀, 2:1 정거원통도법 레이아웃, 투명 배경 PNG로 만들어 줘. 희고 부드러운 구름이 드문드문 분포하며 아래 지표를 대부분 볼 수 있는 얇은 구름층이야. 지표, 바다, 대륙, 별, 우주 배경, 대기 테두리, 빛 번짐, 그림자, 글자를 포함하지 마. 좌우 경계가 자연스럽게 이어지고, 구름 가장자리에는 검은색이나 흰색의 불투명 배경 잔여물이 없어야 해. 특정 날짜의 실제 날씨를 재현하는 이미지가 아니라 관찰 장식용 표현이야.

**적용:** 지표 관찰·스캔에서는 구름을 숨길 수 있게 해. 구름 자체가 대기 전체라는 오해를 주지 않게 대기 안내와 분리해.

# E04 지구 외형 기준 이미지 프롬프트

**참조:** 검증된 지구 지도와 기존 1장 화면 샘플, 파랑·청록 계열 조사본부 배경.

**복사해서 쓰는 이미지 생성 프롬프트**

초등학교 3학년 과학 탐구 게임 푸른행성 조사본부의 지구 관찰 오브젝트 외형 기준 이미지를 만들어 줘. 실제 지구의 대륙 윤곽을 유지한 완전한 구형 지구 한 개를 화면 중앙에 배치해. 동아시아와 태평양이 보이고, 전체 구체가 잘리지 않으며 사방에 10퍼센트 여백이 있어. 맑은 파랑 바다, 자연스러운 초록·황갈색 육지, 부드럽고 밝은 게임 일러스트 질감, 과하지 않은 입체감으로 표현해. 얼굴, 팔다리, 눈, 의인화를 넣지 마. 1024×1024픽셀 투명 배경 PNG. 받침대, 우주 배경, 별, 글자, 버튼, HUD, 국경선, 과장된 대기 고리 없이 지구만 그려 줘. 표면을 가리는 구름과 강한 반사광은 넣지 마.

**용도:** 분위기와 가독성 확인에만 사용해. 이 한 장을 지구 전체 표면에 늘려 붙이거나, 보이지 않는 뒤쪽 대륙을 추정하는 자료로 사용하지 않아.

# E05 2D 대체 이미지 제작 지시

E01·E02를 적용한 같은 지구 모델에서 동아시아·태평양·아프리카 및 유럽·아메리카 중심의 네 방향을 동일 크기와 조명으로 렌더해. 각각 투명 PNG로 저장해. 이미지마다 별도의 AI 지구를 생성하지 않아.

대체 화면에서는 좌우 버튼으로 방향을 바꾸고 미리 검수한 관찰 지점을 선택할 수 있게 해. 3D를 사용할 수 없어도 표본 수집·대기 관찰·다음 화면의 비교 활동까지 완료할 수 있어야 해.

# 2.5D 허브와 혼동하지 않을 점

허브에 필요한 것은 3D 모델보다 **일관된 사선 시점의 픽셀아트 맵과 캐릭터 스프라이트**야. 기존 폴더에는 이 용도에 바로 사용할 맵·걷기 시트가 확인되지 않았어.

허브의 제안 장소는 지구 관측소, 물 표본 실험실, 해안 조사 입구, 조석 관측소, 갯벌 탐사 입구야. 하나의 자연 공간에서 길로 연결하고, 각 장소에 들어가면 해당 2D 학습 화면으로 전환해.

이 허브의 픽셀아트 제작 목록과 프롬프트는 3D 지구 제작 목록과 별도로 확정해. 캐릭터 3D화, 연구소 전체 3D화, 실시간 3D 파도·갯벌은 현재 MVP 범위에 넣지 않아.

# 제작 순서와 참고 자료

1. 지리 자료를 정하고 E01·E02 좌표를 맞춰.
2. 구체 회전·스캔과 대기 관찰 기능을 연결해.
3. 필요할 때만 E03과 E04를 제작해.
4. 실제 구현한 지구에서 E05를 추출해.
5. 태블릿에서 대륙 가독성, 회전 입력, 표본 판정, 2D 대체 경로를 확인해.

NASA Blue Marble은 위성 관측을 합성한 지구 시각 자료를 제공해. 지표·구름 자료의 출처와 크레딧을 확인할 출발점으로 사용할 수 있어. 실제 채택할 파일의 투영법과 이용 조건은 제작 때 확인해. [NASA Blue Marble 설명](https://science.nasa.gov/earth/earth-observatory/the-blue-marble-true-color-global-imagery-at-1km-resolution/)

설계 배경: [기존 공유 대화](https://chatgpt.com/share/6aced5e8-476c-83ee-876f-68c12498117c). 이번 대화에서 확정한 ‘지구 관찰에만 3D 추가’를 예전 문서의 여러 화면 3D 계획보다 우선 적용해.
