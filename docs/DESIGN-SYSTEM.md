# 푸른행성 조사본부 · 디자인 시스템

## 방향

초등 3~4학년의 과학 탐사를 **작은 연구소와 현장 기록장**으로 표현한다. 스테이지 선택은 2.5D 픽셀 탐사 지도, 시설 안은 기존 2D 현장 이미지와 조작 패널을 쓴다. 배경·캐릭터·로고는 기존 에셋을 재사용하며 글과 조작부는 HTML로 유지한다.

첫 화면은 왼쪽 크림색 편지 패널과 오른쪽 부리·짱이로 역할을 나눈다. 주 행동은 청록색 버튼 하나, 보상은 살구색 배지로 구분한다. 학습 화면은 `관찰 대상 → 한 문장의 지시 → 직접 조작 → 증거와 설명 → 기록/보상` 순서로 읽힌다.

## 토큰과 비례

정의: `src/design-tokens.css`. 기존 CSS 변수는 유지해 화면별 스타일과 호환한다. 프로젝트의 크림·남색·청록 팔레트를 교육 UI의 기본 파랑 예시보다 우선 적용한다.

| 역할 | 값 | 사용 |
|---|---|---|
| 본문 / 보조문 | `--ink: #173f4b` / `--muted: #47666b` | 핵심 설명 / 보조 안내 |
| 기기 / 주 행동 | `--navy: #103e4e` / `--teal: #086c6b` | 헤더·관찰 장치 / 확인·진행 |
| 종이 / 바탕 | `--paper: #fffdf5` / `#f2f3e9` | 학습 카드 / 화면 바탕 |
| 보상 | `--gold: #f3c98d` / `--apricot: #f8e0bc` | 배지·획득 정보. 본문은 남색 |
| 판정 | 성공 `#216343`, 다시 보기 `#a23f32` | 설명 문구·기호·테두리와 함께 표시 |

본문은 로컬 BluePlanetBody, 제목은 BluePlanetDisplay를 사용한다. 학습 본문은 **20~30px·줄높이 1.4~1.65**, 화면 제목은 28~44px, 보조 라벨은 17~24px다. 핵심 안내와 선택지는 좁은 화면에서도 18px 이상을 유지한다. 한글은 `keep-all`로 어절을 지키고, 긴 내용은 줄바꿈과 높이 확장으로 수용한다.

간격은 4·8·12·16·24·32px, 큰 카드 안쪽은 24~30px, 카드 사이 24px을 사용한다. 모서리는 8·12·20px, 그림자는 작은 조작부와 큰 패널 두 단계로 제한한다. 버튼은 단색으로 유지하고 선택 상태는 테두리와 체크를 함께 쓴다.

## 공통 컴포넌트

- `.primary`: 다음 진행·답 확인. 화면당 한 가지 주 행동을 강조한다.
- `.secondary`: 다시 보기·돌아가기. `.danger`는 기록 초기화에만 사용한다.
- `.work-panel`: 불투명한 종이 표면. 배경 위에 본문을 직접 놓지 않는다.
- `.observation-panel`: 남색 장치 표면. 흰색/연한 크림 글자로 정보를 구분한다.
- `.choice` / `.challenge-option`: 선택지. 최소 48px, 여러 줄 허용, 체크·선택 테두리 제공.
- `.challenge-progress`: 활동 진행과 수집 상황. 원본 관찰과 확장 활동을 구분한다.
- `.challenge-feedback`: 정답 이유와 재도전 안내. 색에만 의존하지 않는다.
- `.reward-dialog`: 획득한 기록과 다음 행동. 닫기·진행 버튼을 같은 위치에 둔다.

설정은 `settings.css`, 지도는 `hub.css`에서 해당 화면의 세부 배치를 담당한다. 공통 아이콘은 현재 색상을 따르는 SVG로 통일하고, 조작 아이콘에는 텍스트 또는 접근성 이름을 함께 둔다.

## 반응형과 접근성

- 우선 검증: 1280×800, 1024×768 가로 태블릿. 두 열에서 관찰 영역에 약 55~60%를 배분한다.
- 확장 도전은 관찰 자료 40%·문제 조작 60%를 기준으로 한다. 다음 행동은 활동 아래 전용 행에 놓고 네 문제를 완료하면 다음 단계 버튼으로 전환한다. 학습 화면과 교사 도구는 문서 흐름을 따라 배치해 서로 덮지 않는다.
- 학습 화면은 뷰포트 높이 안에 상단 단계·활동·하단 조작 바를 배치한다. 가로 화면에서는 두 열을 유지하고, 세로 화면에서는 관찰·조작 영역을 나눠 모두 보이게 한다. 중복 지시를 없애고 보충 설명은 별도 대화상자로 연다.
- 500px 이하는 선택지와 정보 카드를 세로로 쌓는다. 터치 대상은 모든 크기에서 48×48px 이상이다.
- 포커스는 3px 외곽선과 3px 간격으로 표시한다. `prefers-reduced-motion`에서는 애니메이션과 전환을 끈다.
- 설정·보상은 HTML dialog를 사용한다. 배경 조작 차단과 닫은 뒤 포커스 복원은 스크립트에서 담당한다.

정적 대비 계산(종이색 `#fffdf5` 기준): 본문 **11.15:1**, 보조문 **6.10:1**, 청록 **6.12:1**, 성공 **7.04:1**, 재도전 **6.26:1**. 모두 일반 글자 4.5:1 기준을 충족한다. 실제 겹침·잘림·조작 흐름은 브라우저 검증 결과로 별도 확인한다.

## 스테이지 관찰 자료 · 2026-11-08

- 공통: 선택 기호·문장에 별도 공간을 주고, 제목·단계 탭·힌트·진행 버튼은 줄바꿈한다. 표본과 선택지는 글 길이에 따라 높이가 늘어난다.
- 지구: 전체 면적 자료와 내가 모은 지점 표본을 구분한다. 바다·육지는 색과 글자를 함께 사용한다.
- 실험: 투명한 비커·눈금·물·가열대·남은 흔적을 구분한다. 양과 결과 라벨은 그릇 밖에 놓고 기존 슬라이더 및 가열 상태와 연결한다. 실제 실험을 단순화한 모형임을 밝힌다.
- 해안: 장면의 촬영 위치와 조작 안내를 분리한다. 사진 위 핀과 앨범 설명을 가리지 않는다.
- 조석: 같은 기둥·바위를 기준으로 시각과 물 높이를 비교한다. A/B 라벨과 비교선 조작부를 분리한다.
- 갯벌: 관찰 원의 중심을 실제 흔적 좌표에 고정한다. 긴 흔적 이름은 별도 라벨로 표현하고, 확대 생물과 특징 설명을 나란히 비교한다.
- 도전·적용: 과제의 실험·해안·지구·조석·생태 자료를 DOM/CSS/SVG로 표현한다. 관측 그림은 문항 조건에 맞추며 새로운 측정값을 만들어내지 않는다.

구현 계층: 기존 `experience.css` 다음에 `science-stages.css`, `field-stages.css`, `challenge-stages.css`, 공통 배치 `responsive-stages.css`를 적용한다. 상태 저장·정답 판정·완료 조건은 기존 모듈을 유지한다.

## 납품 화면 기준 · 2026-11-11

- 실제 글꼴은 네이버 나눔스퀘어 네오 원본 Regular·Bold·ExtraBold다. BluePlanetBody·BluePlanetDisplay는 CSS 별칭으로 사용한다.
- 유리 패널의 학습 본문에는 `--glass-read`를 적용한다. 흐림 효과를 지원하지 않는 환경에는 불투명한 종이색 표면을 제공한다.
- 모든 조작 대상은 48px 이상으로 유지한다. 좁은 홈 화면에서는 시작·지도·목소리 버튼을 별도 행과 열에 배치한다.
- 조석 비교는 화면에 렌더링된 관찰 그림 높이를 최소 130px로 확보한다. 짧은 가로 화면에서는 비교선·기준물 확인을 아래 한 행에 모은다.
- 탐사 지도와 조작 패널을 분리하고 관측점 이름표·탐사정에 별도 공간을 준다. 탐사정 이동 후 포커스를 유지하며 짧은 화면의 대화상자 닫기는 고정 헤더에 둔다.
- 관측 기록과 장 배지는 첫 완료에만 보상 연출을 낸다. 재방문은 기록 확인과 다음 탐사로 이어진다.
- 학습 화면과 홈에 기기의 안전 영역을 반영하고 인증서는 A4 가로 한 장과 배경색 유지로 출력한다.

## 한 화면 활동과 자동재생 (2026-11-08)

- 활동은 남는 높이와 가로폭을 모두 사용한다. 다음 버튼은 활동과 분리한 마지막 행에 항상 둔다. 교사 이동은 작은 도구로 접어 같은 공간을 반복 점유하지 않는다.
- 할 일은 하단 한 문장으로 표시하고 현재 조작 대상에 테두리를 준다. 선택지의 정답은 안내로 노출하지 않는다.
- 지구 관찰·조건 맞추기·가열·해안 촬영·조석 관측·비교·생물 확대에 자동재생/일시정지와 0.5·1·2·3배속을 제공한다. 예상·분류·특징·정답은 사용자가 고른다. 답 선택 대기, 화면 이동, 설정 열기, 탭 비활성 시 재생을 멈춘다.
- 가열의 진행률과 물 높이는 같은 시간값으로 갱신한다. 일시정지·속도 변경·이탈 시 뒤늦은 완료가 발생하지 않아야 한다. 저장 형식과 기존 채점 규칙은 유지한다.
- 검증: 전체 20화면과 확장 40문제에서 문서/활동의 세로·가로 넘침, 버튼 가림, 텍스트 잘림을 측정한다. 자동재생의 답 미선택·중지·재개·속도·화면 이탈을 실제 브라우저로 확인한다.
