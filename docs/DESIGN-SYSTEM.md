# 푸른행성 조사본부 · 디자인 시스템

## 방향

초등 3~4학년의 과학 탐사를 **작은 연구소와 현장 기록장**으로 표현한다. 스테이지 선택은 2.5D 픽셀 탐사 지도, 시설 안은 기존 2D 현장 이미지와 조작 패널을 쓴다. 배경·캐릭터·로고는 기존 에셋을 재사용하며 글과 조작부는 HTML로 유지한다.

첫 화면은 왼쪽 크림색 편지 패널과 오른쪽 부리·짱이로 역할을 나눈다. 주 행동은 청록색 버튼 하나, 보상은 살구색 배지로 구분한다. 학습 화면은 `관찰 대상 → 한 문장의 지시 → 직접 조작 → 증거와 설명 → 기록/보상` 순서로 읽힌다.

## 토큰과 비례

정의: `src/design-tokens.css`. 기존 CSS 변수는 유지해 화면별 스타일과 호환한다. 프로젝트의 크림·남색·청록 팔레트를 교육 UI의 기본 파랑 예시보다 우선 적용한다.

| 역할 | 값 | 사용 |
|---|---|---|
| 본문 / 보조문 | `--ink: #173f4b` / `--muted: #47666b` | 핵심 설명 / 보조 안내 |
| 기기 / 주 행동 | `--navy: #103e4e` / `--teal: #086c6b` | 헤더·관찰 장치 / 확인·진행 |
| 종이 / 바탕 | `--paper: #fffdf5` / `#f2f3e9` | 학습 카드 / 화면 바탕 |
| 보상 | `--gold: #f3c98d` / `--apricot: #f8e0bc` | 배지·획득 정보. 본문은 남색 |
| 판정 | 성공 `#216343`, 다시 보기 `#a23f32` | 설명 문구·기호·테두리와 함께 표시 |

본문은 기존 시스템 한글 폰트, **18px·줄높이 1.65**를 기준으로 한다. 화면 제목은 28~36px, 패널 제목은 23~28px, 보조 라벨은 14~16px다. 핵심 안내와 선택지는 좁은 화면에서도 18px을 유지한다. 한글은 `keep-all`로 어절을 지킨다.

간격은 4·8·12·16·24·32px, 큰 카드 안쪽은 24~30px, 카드 사이 24px을 사용한다. 모서리는 8·12·20px, 그림자는 작은 조작부와 큰 패널 두 단계로 제한한다. 버튼은 단색으로 유지하고 선택 상태는 테두리와 체크를 함께 쓴다.

## 공통 컴포넌트

- `.primary`: 다음 진행·답 확인. 화면당 한 가지 주 행동을 강조한다.
- `.secondary`: 다시 보기·돌아가기. `.danger`는 기록 초기화에만 사용한다.
- `.work-panel`: 불투명한 종이 표면. 배경 위에 본문을 직접 놓지 않는다.
- `.observation-panel`: 남색 장치 표면. 흰색/연한 크림 글자로 정보를 구분한다.
- `.choice` / `.challenge-option`: 선택지. 최소 48px, 여러 줄 허용, 체크·선택 테두리 제공.
- `.challenge-progress`: 활동 진행과 수집 상황. 원본 관찰과 확장 활동을 구분한다.
- `.challenge-feedback`: 정답 이유와 재도전 안내. 색에만 의존하지 않는다.
- `.reward-dialog`: 획득한 기록과 다음 행동. 닫기·진행 버튼을 같은 위치에 둔다.

설정은 `settings.css`, 지도는 `hub.css`에서 해당 화면의 세부 배치를 담당한다. 공통 아이콘은 현재 색상을 따르는 SVG로 통일하고, 조작 아이콘에는 텍스트 또는 접근성 이름을 함께 둔다.

## 반응형과 접근성

- 우선 검증: 1280×800, 1024×768 가로 태블릿. 두 열에서 관찰 영역에 약 55~60%를 배분한다.
- 확장 도전은 관찰 자료 40%·문제 조작 60%를 기준으로 한다. 801px 이상에서는 확인 버튼을 화면 아래에 붙이고, 네 문제를 완료하면 다음 단계 버튼으로 전환한다. 확인·다음 단계의 두 행동 바가 겹치지 않게 한다.
- 800px 이하는 한 열로 바꾸고 조작부를 줄바꿈한다. 작은 화면에서 글씨를 줄이거나 설명을 숨기는 방식으로 맞추지 않는다.
- 500px 이하는 선택지와 정보 카드를 세로로 쌓는다. 터치 대상은 모든 크기에서 48×48px 이상이다.
- 포커스는 3px 외곽선과 3px 간격으로 표시한다. `prefers-reduced-motion`에서는 애니메이션과 전환을 끈다.
- 설정·보상은 HTML dialog를 사용한다. 배경 조작 차단과 닫은 뒤 포커스 복원은 스크립트에서 담당한다.

정적 대비 계산(종이색 `#fffdf5` 기준): 본문 **11.15:1**, 보조문 **6.10:1**, 청록 **6.12:1**, 성공 **7.04:1**, 재도전 **6.26:1**. 모두 일반 글자 4.5:1 기준을 충족한다. 실제 겹침·잘림·조작 흐름은 브라우저 검증 결과로 별도 확인한다.
