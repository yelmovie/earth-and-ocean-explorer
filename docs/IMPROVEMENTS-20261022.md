# 고도화 기록 — 2026-10-22

## 해결할 문제
기존 MVP는 5장×2화면으로 짧고, 지도는 단순한 도형 건물과 한 캐릭터였다. 설정 순서·소리 제어가 공통 규격과 달랐고, 작은 화면 규칙 중 일부는 안내문을 숨기거나 글자를 줄였다.

## 바뀐 학습 경험
각 장을 관찰·비교·도전·적용으로 확장했다. 학습 화면10→20, 추가40문제를 데이터로 분리했다. 지구는 표본과 전체 면적을 구분하고, 실험은 공정한 조건과 잔류물을 해석하고, 해안은 사진의 재료·형태를 연결하고, 수면은 같은 기준물을 시간순으로 비교하고, 갯벌은 주장·증거·행동으로 보호 안내판을 만든다. 막연한 클릭 횟수가 아니라 관찰과 검증된 답에 완료를 연결했다.

## 시각·흥미
새 섬 이미지와 시설5종을 생성해 적용했다. 지도에서 부리는 흙길을 걷고 짱이는 발자취를 따라온다. 건물의 불빛은 저장된 완료 기록에서 계산한다. 시설 내부는 기존 장소 일러스트를 유지하면서 크림색 학습 카드, 청록색 행동, 공통SVG와 큰 한글 안내를 적용했다. 장 완료의 세 탐구 별과 배지, 내 기록 보고서, 엔딩과 인증서를 연결했다.

## 코드·운영
확장 활동 데이터/검증, 지도 기하/입력, 소리, 아이콘, 설정 문구, 디자인 토큰을 분리했다. 새 형식에서 solved 문자열만 바꾸는 것으로는 진도를 얻지 못한다. 이전 버전의 실제 증거는 보존한다. 관리자 전체 해금은 실제 완료와 분리하며, 초기화는 소리를 남긴다. 21개 단위 테스트와 Edge 실제 조작·뷰포트 검증으로 회귀를 확인한다.

## 아직 제품 검증이 필요한 것
문제를 늘린 것이 실제 학습효과나 흥미 향상으로 이어졌는지는 학생 관찰과 교사 검토가 필요하다. 실제 기기, 학교망 부하, 기존 제공 이미지의 상업 이용권 증빙은 납품 전 확인한다. 최종 결과와 미검증은 reviews 보고서를 따른다.
