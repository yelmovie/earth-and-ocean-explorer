## 3. 중복 조작 버튼 전수 점검

모든 화면(홈 → 지도 → 5장 × 관찰·비교·도전·적용 → 보고서 → 증거 연결 → 엔딩 → 인증서)에서 보이는 조작 요소를 `measure.json`의 `controls`로 뽑아 대조했다.

| 화면 | 중복 | 처리 |
|---|---|---|
| 1장 관찰(s1a) | 3D 지구를 손으로 끌어 돌릴 수 있는데 「↶ 왼쪽」「오른쪽 ↷」 버튼이 같은 일을 함 | **두 버튼 제거.** 지구 자체가 초점을 받고 왼쪽·오른쪽 화살표 키로 돈다(`src/globe.js`, `#globe` tabindex·안내). 「대기 관찰」은 유지 |
| 증거 연결(link) | 증거와 이유를 고르면 바로 확인되는데, 늘 꺼진 진한 「연결 확인」 주 버튼이 「다음 상황 →」 옆에 있음(꺼진 주 버튼 + 연결 뒤 「✓ 연결 완료」가 상황 카드·번호 탭과 세 겹) | **누를 일이 없을 때 숨김.** 틀린 뒤나 이미 연결한 상황의 답을 바꿨을 때만 보인다(그때는 유일한 확인 경로라 유지). `src/main.js` `syncLinkGuidance` |
| 홈 | 위 띠 ▷「대사 다시 듣기」와 「부리 목소리 듣기」 — 같은 부리 음성 듣기 버튼이 두 개 | **위 띠 ▷를 홈에서 숨김**(지도와 같게). 홈에서 말풍선 대사 다시 듣기는 설정 창에 둠 |
| 4장 비교(s4b) | 비교선을 끌면 기둥·바위가 기록되는데 「기둥에서 비교」「바위에서 비교」 버튼도 기록 | **유지** — 버튼이 기록 상태(✓ 비교함)를 보여 주는 유일한 표시이고, 비교선을 대상 위치로 옮겨 주며, 납품 완주 검사(`tests/release-browser.mjs`)의 조작 경로다. 보수적으로 유지 |
| 5장 관찰(s5a) | 돋보기 끌기 + 흔적 버튼 | 유지 — 흔적 버튼이 장면 속 물체 자체다 |
| 지도 | 방향판·손 이동·전체 보기·모아 말풍선·보고서 버튼 | 유지 — 서로 다른 일. 악당·성취 카드 작업 직후라 손대지 않음 |
| 활동 아래 띠 | 안내·자동재생·도움말·주 버튼 1개 | 유지 — 「더 알아보기」는 도움말 말풍선 안에만 있다 |
| 도전·적용 | 문제 번호 탭 + 주 버튼 | 유지 — 번호 탭은 진행 알약 |

정리: 없앤 버튼 2개(지구 회전), 상황에 따라 숨긴 버튼 2개(연결 확인, 홈 ▷), 유지 판단 5곳.
