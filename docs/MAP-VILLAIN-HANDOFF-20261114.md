## 외형과 등장

**물때 교란 부표 / 크림·산호색 몸통, 길에서 바다 쪽으로 틀어진 큰 주황 표지.** 스테이지 완료 기록 후 지도에 돌아올 때 해당 장소 옆에 등장한다. 기존 주인공·동료·건물의 스타일을 유지하고, 악당과 소품의 접점이 글 없이도 읽히게 그린다. 아래 소품 동작은 지도 위 짧은 장난 컷이다. 활동 화면이나 기존 학습 데이터에는 손대지 않는다.

지도 부리·짱이 기존 그림을 기준으로 별도 피격 시트. 개념 영상 캐릭터와 섞지 않는다. 화살표는 장식이고 실제 이동 안내와 구분한다.

## 스테이지마다 바뀌는 소품·자세·대사

장소명은 기획상의 연결 기준이다. 활성 버전의 스테이지 ID와 이름을 대조한 뒤 키를 정한다. 선택 구역은 실제 별도 완료 이벤트가 있을 때만 추가한다.

| 장소 | 악당 스프라이트 동작 | 첫 등장 또는 접근 대사 예시 |
|---|---|---|
| 지구 관측소 | 지도 축척판 위에 뒤집은 깃발 올리기 | “이 깃발은 반대로 꽂지!” |
| 물 표본 실험실 | 표본 라벨 두 장을 낚아채기 | “물 표본 이름표는 내가 가져갈게!” |
| 해안 조사구역 | 길 안내 화살표를 바다로 돌리기 | “그 길은 이쪽이라고 해 두자!” |
| 밀물·썰물 관측소 | 수위 눈금 표지 옆에 몸으로 가리기 | “높이가 잘 안 보이지?” |
| 갯벌 탐사구역 | 관찰 구역 표찰을 자기 쪽으로 돌리기 | “갯벌 표찰은 내 쪽이야!” |

상황 대사 예시:

- 접근: “표지판이 가리키는 데를 봐!” / “부표가 하는 말이라면 믿겠지?”
- 1·2타: “앗, 한 번 크게 흔들렸어!” / “화살표가 돌아가잖아!”
- 퇴장: “파도 타고 갈래!” / “표지판은 제자리로!”

스테이지 고유 문장을 우선하고, 상황 대사는 연속 반복 없이 고른다. 주인공·보조 캐릭터의 주민 대화와 겹칠 때는 악당 말풍선을 생략한다.

## 세 번의 타격과 접촉 피격

| 사건 | 이 프로젝트의 표현 |
|---|---|
| 1타 · 짧은 명중 | 반달형 물결이 부표 아래 번짐 |
| 2타 · 더 큰 반동 | 부표가 기울고 물결 두 줄이 짧게 퍼짐 |
| 3타 · 마무리와 퇴장 | 화살표가 제자리로 돌아오고 부표가 통통 떠서 퇴장 |
| 주인공 접촉 | 부리는 중심을 낮추고 몸을 흔들며 한 걸음 밀림 |
| 보조 캐릭터 접촉 | 짱이는 날개나 팔을 벌렸다 접으며 짧게 버팀 |
| 악당의 접촉 공격 동작 | 부표가 옆으로 기울고 작은 반달 물결이 한 번 닿음. 화면 전체는 움직이지 않음. |
| 타격·퇴장 효과음의 차이 | 퐁 → 첨벙 → 풍덩 |
| 접촉 효과음 모티프 | ‘첨벙, 퐁’ |

세 타격은 같은 공격 입력이다. 가까이 있는 상태에서 한 입력이 한 타로 계산된다. 접촉 피격은 닿은 쪽만 재생하고 공격 카운트와 학습 진행에는 영향을 주지 않는 것을 권장한다. 소리를 꺼도 표정·자세·게이지로 읽혀야 한다.

## 방향과 시선

[공통 방향 규칙](../../_shared/MAP-VILLAINS-HANDOFF-20261114.md#방향시선공격-자세)을 적용한다. 악당의 얼굴은 주인공 쪽을 보되, 장난용 표지판은 지도에서 정한 물가 방향을 유지한다. 본체 반전으로 안내 화살표가 바뀌면 안 된다.

## 제작하고 적용할 순서

1. 기존 진입점 확인: [src/data.js](../src/data.js) · [src/hub-world.js](../src/hub-world.js) · [README.md](../README.md). 활성 지도와 완료 상태, 실제 주인공/보조 지도 원본·이름, 기존 악당/스프라이트·대사·저장부터 확인한다.
2. 기본 악당 한 장, 위 표의 장소별 소품 동작 스트립, 공통 이동/접촉 전조/피격/퇴장 프레임을 제작한다. 주인공·보조 피격은 각각 4~6프레임. 소품이나 배경을 몸통 시트에 같이 구워 넣기 전에 지도 크기에서 알아볼 수 있는지 확인한다.
3. 별도 승인된 구현 단계에서 완료된 장소 좌표에 악당을 붙이고, 기존 HUD 근처에서 공격·타격·피격·퇴장만 연결한다. 기존 이동/화면 전환/복구 상태와 학습 완료/다음 장소 해금은 보존한다.
4. 완료 전/후, 정확한 3타, 두 아군의 개별 접촉, 퇴장 및 재진입, 빠른 연타, 무음·모션 감소·태블릿을 확인한다. 가장 작은 정상 지도 표시 크기에서 소품과 방해 동작이 구분되는지 본다.

완료된 것: 정적 이미지 합성과 계획. 남은 것: 기존 시트/캐릭터 일치 확인, 프레임 제작, 대사 최종화, 구현 및 테스트. 06 물의 상태 변화는 참고 전용.
