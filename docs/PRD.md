# 푸른행성 조사본부 — MVP PRD v3

확정: 2026-10-22. 이번 사용자 요청을 반영하며 v2의 신규 이미지 제외·학습 10화면 조건을 대체한다. 실제 구현과 후속 납품 조건을 구분한다.

## 1. 제품 목표
초등 과학 ‘지구와 바다’에서 학생이 관찰 → 비교 → 근거 설명 → 생활 속 적용을 경험한다. 사라진 조사 기록 다섯 묶음을 부리·짱이와 복구하고, 시설 불빛·탐사 배지·엔딩·개인 관찰 인증서를 얻는다. 자연현상을 장비가 만들거나 학생이 조종하는 설정은 쓰지 않는다. 타이머·목숨·속도 순위·개인정보 입력은 없다.

## 2. 교육과정과 한계
2022 개정 과학 [4과06-01~03]에 연계한다. 코드·원문은 설정 > 교사용 가이드 > 성취기준에서 볼 수 있다. 경기도교육청 공개 PDF의 부록2 과학 ‘지구와 바다’ 원문을 2026-10-22 대조했다.
원문 근거: https://www.goe.go.kr/resource/old/BBSMSTR_000000030136/BBS_202411110127574203.pdf

- 지구 표면의 육지·바다와 지구를 둘러싼 공기를 구별하고, 전체 자료에서 바다가 더 넓음을 정성적으로 비교한다. 71% 암기나 표본 수를 전체 면적으로 간주하는 활동은 하지 않는다.
- 육지의 물과 바닷물을 같은 조건으로 가열한 가상 실험에서 남는 물질을 비교한다. 가열이 소금을 새로 만든다는 오개념을 다룬다. 실제 가열 안전을 안내한다.
- 해안의 재료·모양을 조사한다. 침식·운반·퇴적 원리는 평가하지 않는다.
- 같은 장소·기준물에서 시간에 따른 수면 변화를 비교한다. 밀물·썰물의 원인이나 조석 예보는 다루지 않는다.
- 생물의 특징과 서식처를 관찰하고, 그 증거로 갯벌 보전의 필요성과 행동을 설득한다.

성취기준 전체 달성이나 학습효과를 앱 완주만으로 확정하지 않는다. 교사 검토·대화·후속 수행평가를 함께 한다. 학생 대상 효과 검증은 아직 실시하지 않았다.

## 3. 화면 범위와 학습 분량
메인 → 탐사 지도 → 5장 × 4화면 → 최종 보고서 → DATA LINK → 2D 엔딩 → 인증서. 총 26개 경로. 학습 화면은 기존 10개에서 20개로 정확히 2배 확대했다. 기존 관찰·비교 활동을 유지하면서 장마다 필수 확장 문제 8개, 합계 40개를 추가했다. 분류·특징 연결 문제는 여러 하위 판단을 포함하므로 ‘기존 클릭 수의 2배’라는 계산은 하지 않는다.

| 장 | a 관찰 | b 비교 | c 도전 4문제 | d 적용 4문제 | 연결 목표 / 보상 |
|---|---|---|---|---|---|
| 1 지구 관측소 | 지구 회전·3곳 이상 스캔·육지/바다 모두·대기 관찰 | 표본 분류·전체 면적과 구별 | 지표 분류, 공기 설명, 전체 면적 그림, 자료 범위 분류 | 새 섬, 편중된 표본, 설명 연결, 안내문 판단 | 01 / 관측소 불빛·관찰 배지 |
| 2 물 표본 실험실 | 같은 물의 양·가열 세기·예상 | 가열 전후·잔류물·물질의 출처 | 조건 분류, 실험 순서, 불공정 조건 수정, 잔류물 근거 | 미지 표본, 가열 조건 수정, 증거 연결, 안전 행동 | 02 / 표본대·실험 배지 |
| 3 해안 조사구역 | 모래사장·절벽·동굴·구멍 난 바위 촬영 | 특징 핀·설명·두 바위 비교 | 4지형 연결, 재료 분류, 관통 공간 관찰, 조사 순서 | 새 지형, 잘못된 표지, 안전 경로, 다양한 해안 근거 | 02 / 앨범·사진 배지 |
| 4 조석 관측소 | 시간축·수면 높이가 다른 A/B 기록 | 기준물 두 개·변화 방향·밀물/썰물 | 시간 순서, 상승/하강/같음 연결, 밀물 근거, 잠김/드러남 분류 | 썰물 근거, 추가 관측 필요, 실제 해안 안전, 모형 해석 | 03 / 관측 게시판·시간 배지 |
| 5 갯벌 탐사구역 | 3생물 흔적·확대·특징 | 갯벌 가치·근거 있는 보호 행동 | 생물 연결, 행동 분류, 가치 근거, 탐사 순서 | 주장/증거/행동 안내판, 친구 설득, 구멍 보전, 생활 약속 | 03 / 생태 안내판·보호 배지 |

권장 조작은 한 문장으로 제시한다. 카드 선택 → 분류함 선택이 기본이며 마우스 드래그를 보조 제공한다. 순서 배열은 카드를 차례대로 눌러 만들고 마지막 카드를 되돌릴 수 있다. 오답 후 해당 단서를 열어 비교하게 하며 벌점·진행 초기화는 없다.

## 4. 지도와 시각 방향
스테이지 선택만 2.5D 픽셀 RPG다. 생성한 섬 배경과 시설, 픽셀 부리·짱이를 사용한다. 부리는 실제 흙길을 따라 이동하고 짱이는 지나온 발자취를 따라온다. 지도는 확대되어 카메라가 따라가고, 목적지 이름표·방향판·다음 목적지 버튼·동행 안내만 얹는다. 잠긴 시설도 걸어가서 이유를 들을 수 있다. 열린 문에 닿을 때 한 번 입장하며, 돌아오면 그 문 앞에 선다. 내부는 기존 PNG를 활용한 2D 학습 화면이다. 기존 지구 관측 패널의 회전 가능한 3D 지구만 유지한다.

크림 종이·남색 텍스트·청록 주행동·금빛 보상. 본문 18px, 핵심 제목 28~36px 이상, 48px 터치 목표, 한글 어절 줄바꿈, SVG 공통 아이콘을 적용한다. 과학 정보를 장식 그림만으로 판단시키지 않고 관찰 자료·설명을 함께 제시한다.

## 5. 보상과 재방문
각 장의 관찰/비교/도전/적용을 모두 마쳐야 실제 배지를 얻는다. 8문제에서 검증된 정답이 있는 경우에만 완료한다. 배지는 중복 지급하지 않는다. 장 완료 대화에서 기록·세 탐구 별을 보여주고, 지도 창문과 시설이 밝아진다. 보고서는 최초 관찰의 표본·조건·핀·시각·특징과 확장 활동을 보존한다. 최종 DATA LINK는 5개의 새 상황에서 기록과 이유를 함께 연결해야 한다. 이후 엔딩과 인증서가 열리며 인증서에는 할 수 있게 된 행동을 진술한다.

재방문은 원래 증거를 지우지 않고 같은 조사 도구와 다른 관측 지점/시각/예상으로 탐구를 다시 할 수 있다. 학습효과 없는 무작위 포인트 누적이나 속도 보상은 없다. 추가 랜덤 문항은행·반복 완주용 별도 캠페인은 후속 범위다.

## 6. 설정·저장·교사용 해금
설정 순서는 배경음/효과음 개별 켜기 → 배경음 음량 → 동기 이야기 다시 보기 → 앱 정보 → 학생 → 교사 → 저작권 → 초기화/닫기다. 처음 접힘은 모두 닫는다. 교사용 도구의 전체 해금 토글 하나가 26경로를 함께 연다. 비밀번호·화면별 바로가기 목록은 없다. 해금은 완료·증거·인증을 만들지 않는다. 미수행 화면은 연습으로 표시하고 인증서 인쇄를 막는다. 해제하면 원래 학생 진행으로 돌아간다.

동일 브라우저에 자동 저장한다. 이름·학번·연락처나 외부 분석 요청은 없다. 저장 실패/손상 경고와 메모리 진행을 제공한다. 초기화는 취소에 첫 포커스를 주는 확인 단계가 있으며 소리 설정은 유지한다. v2 진짜 기록은 보존하되 새 확장 활동을 수행한 것처럼 만들어내지 않는다.

## 7. 수용 기준
- 새 사용자로 5장 관찰·비교와 40확장 문제, DATA LINK, 인증서를 끝까지 조작 가능.
- 틀린 답·비어 있는 분류·관리자 미수행은 배지/인증을 만들지 못함.
- 새로고침 시 진행 위치·선택·근거와 소리 설정 유지.
- 5문 모두 걸어서 도달, 도로 밖/바다 이동 방지, 입력 해제 및 복귀 자동 재입장 방지.
- 주요 가로 프로필과 작은 세로 화면에 가로 잘림 없음. 작은 화면은 세로 스크롤 허용.
- 빌드, 자동 단위 테스트, Edge 실제 조작·콘솔 검증 결과를 docs/reviews에 기록.
- ‘10점 품질’은 지향점이며 실측하지 않은 효과·기기·저작권을 만점으로 선언하지 않음.

## 8. 납품 전 남은 확인
학교 실제 태블릿/전자칠판, 학생 읽기·흥미·소요시간, 상업 제공 자산의 생성계정/사용권 증빙, 학교망 부하를 최종 확인한다. 이번 MVP에는 서버·계정·실제 영상 파일·성적 전송·완전 오프라인 PWA를 추가하지 않는다. 외부 공개 배포는 사용자 최종 확인 전 수행하지 않는다.
