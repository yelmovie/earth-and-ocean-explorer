# 푸른행성 조사본부 시나리오 논의안

2026-10-14. 설계 전에 대화하기 위한 정리이며 새 PRD·TRD 확정본이나 구현 결과가 아니야.

## 확인한 흐름

[공유 대화](https://chatgpt.com/share/6aced5e8-476c-83ee-876f-68c12498117c)의 최신 본문은 5개 Mission × 각 2화면 = 학습 화면 10개로 정리돼 있어. 메인, 허브, Final Report, Final Mission, Final Movie, 인증서는 별도야. QUEST → EVIDENCE → WORLD CHANGE → FINAL REPORT → FINAL MISSION → FINAL MOVIE → CERTIFICATE 흐름과 부리·짱이, 즉시 재시도, 탐구 스타일, Bonus Quest, DATA LINK가 언급돼 있어.

공유 대화의 심화 MD 첨부 본문은 열리지 않았어. 아래 세부 플레이와 보상은 로컬 PRD·화면 샘플을 최신 흐름에 맞게 연결한 논의안이야. 첨부 원문에 있던 확정 규칙으로 보지 않아.

## 이번 대화에서 정한 화면 기준

- 메인: 기존 일러스트와 로고, 2D 캐릭터.
- 메인 다음 스테이지 선택: 자연 속 픽셀아트 2.5D 맵. 위에서 사선으로 내려다보고 캐릭터가 길을 따라 이동해.
- 장소 안: 기존 게임 샘플처럼 2D 배경·도구·CSS UI.
- 예외: 사용자가 허용한 1장 지구 관찰 패널 안의 회전 가능한 3D 지구.
- 모든 화면 왼쪽 위: 홈, 이전 화면. 오른쪽 위: 소리, 설정.
- 설정: ‘관리자 전체 해금’ 하나로 모든 장·하위 학습 화면·최종 콘텐츠 접근을 한꺼번에 열어. 구간별 해금 선택은 만들지 않아.
- 전체 해금은 접근 권한만 바꾸고 실제 조사 기록·완료 상태·인증을 자동으로 만들지 않는 방향을 제안해. 자료가 없는 최종 화면에는 연습용 예시를 명시하고 학생 기록과 분리해.
- 홈에서는 홈·뒤로 아이콘을 유지하되 이동할 곳이 없음을 비활성 상태로 표시해. 이전은 앱 안에서 실제 방문한 화면으로 돌아가며 진행 기록을 유지해.

## 전체 이야기

푸른행성 조사본부의 관측 기록 다섯 종류가 손상됐어. 신입 조사원인 학생이 부리·짱이와 함께 관찰·실험·촬영으로 기록을 다시 모아. 복구되는 것은 관측 장비·기록·전시이며 자연현상을 기계가 만들거나 학생이 조종한다는 설정은 사용하지 않아.

메인 → 자연 탐사 허브 → 각 장소의 두 학습 화면 → 증거 획득 → 허브 복귀와 변화 → 다섯 장 완료 → 보고서 → DATA LINK → 엔딩 → 인증서.

허브의 장소 이름은 지구 관측소, 물 표본 실험실, 해안 조사구역, 조석 관측소, 갯벌 탐사구역으로 제안해. 맵 구성과 조작 캐릭터는 아직 확정 전이야.

## 장별 시나리오

| 장 | 첫 화면 | 두 번째 화면 | 얻는 증거와 허브 변화 제안 |
|---|---|---|---|
| 1 지구 표면 조사 | 3D 지구를 돌리며 여러 방향의 대기·육지·바다를 관찰하고 지표 표본을 모아. | 내 표본을 분류하고 전체 지표 자료와 비교해 육지·바다의 특징과 넓이를 설명해. | 지구 관찰 기록. 관측소 신호와 조사 지도 복구. |
| 2 두 물의 차이 조사 | 육지의 물과 바닷물의 양·가열 조건을 같게 준비하고 실험 전 상태를 기록해. | 가열 전후를 확대해 남은 흔적을 비교하고 차이를 증거로 남겨. | 실험 비교 기록. 실험실의 표본 보관대와 기록판 활성화. |
| 3 해안 지형 조사 | 2D 해안을 좌우로 살펴보며 모래사장·절벽·동굴·구멍 난 바위 등의 특징을 촬영해. | 내 사진에 특징을 표시하고 이름을 연결한 뒤 비슷한 두 지형을 비교해. | 해안 조사 앨범. 허브에 직접 찍은 사진 전시. |
| 4 밀물과 썰물 조사 | 같은 장소의 관측 기록에서 시간축을 움직이고 서로 다른 두 시점을 저장해. | A/B 장면의 길·배·바위·기둥 등을 비교해 물 높이의 변화와 밀물·썰물을 연결해. | 시간 비교 기록. 관측소 비교 게시판 복구. |
| 5 갯벌 생태와 가치 조사 | 구멍·발자국·움직임·식물 일부에서 출발해 확대 관찰과 특징 기록으로 생물을 조사해. | 내가 찾은 생물과 관찰 증거를 갯벌의 가치에 연결하고 보호 행동을 제안해. | 생태 도감과 보호 근거. 생태 안내판 완성, 최종 미션 접근. |

기존 샘플 20번의 ‘최종 보호 브리핑’은 5장 두 번째 화면의 가치 정리에 참고하되, 여러 장의 증거를 모으는 최종 보고서와 역할을 구분하는 방안을 제안해. 같은 브리핑을 두 번 작성하게 하지 않아.

학생이 임의로 모은 몇 개 표본의 개수만으로 지구 전체 면적 비율을 확정하지 않아. 개인 표본과 전체 자료를 구분하고 자료가 더 필요한 경우 추가 조사로 연결해.

2장의 남은 물질은 ‘소금 등 바닷물에 녹아 있던 물질’로 설명하고 맛보기는 넣지 않아. 4장의 시간축은 관측 기록을 탐색하는 조작이며 실제 바다를 조종하거나 조석 시각을 예측하는 기능이 아니야. 5장은 이름 맞히기만으로 끝나지 않게 관찰 특징을 요구해.

## 재미와 몰입을 위한 제안

- 내가 남긴 기록이 실제로 사용돼: 사진이 앨범에, 실험 기록이 비교 자료에, 생태 기록이 최종 주장 근거에 연결돼.
- 허브 복귀 때 장비·전시·NPC 반응이 달라져: 점수 숫자 외에 진행 결과를 직접 보게 해.
- 각 장의 조작을 다르게 해: 회전·스캔 / 조건 조절 / 촬영·표시 / 시간 비교 / 흔적 탐색.
- 틀리면 조사 장소나 필요한 도구를 짚어 주고 바로 다시 시도해. 정답을 즉시 대신 완성하지 않아.
- 최종 DATA LINK는 앞서 모은 증거를 상황에 맞게 사용해야 해결되게 해. 무작위 카드 연결만으로 통과시키지 않아.
- Bonus Quest와 탐구 스타일은 공유 대화에 언급돼 있지만 MVP 필수 여부는 논의 후 정해. 먼저 한 번 완주하는 핵심 흐름을 우선해.
- 엔딩은 조사 기록과 허브 변화가 이어지는 2D 연출을 제안해. 별도 AI 영상 생성 요청으로 해석하지 않아.

## MVP 설계로 넘어갈 때 정리할 항목

1. 허브의 이동 캐릭터와 맵 배치.
2. 장별 완료에 필요한 관찰·증거 개수와 한 장의 목표 플레이 시간.
3. 5장 가치 정리와 최종 보고서·DATA LINK의 구체적인 역할 분담.
4. 이어하기, 음소거, 관리자 전체 해금의 저장 범위.
5. 확보한 배경으로 만들 수 있는 화면과 추가 레이어가 필요한 화면.

다음 PRD는 이 학습 흐름과 완료 조건을, TRD는 허브·2D 화면·지구 패널의 전환 및 증거 저장 구조를 정리할 예정이야. 기존 문서의 P01·P02·P10 3D, 해안·조석 화면 2.5D, 메인 포함 총 10화면 규칙은 이번 기준으로 교체해야 해.
