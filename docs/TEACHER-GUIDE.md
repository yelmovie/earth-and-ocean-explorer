# 교사용 안내 · 푸른행성 조사본부

## 1. 한 줄 소개

사라진 조사 기록 다섯 가지를 찾아 복구하며, 지구와 바다를 관찰하고 증거로 비교해 갯벌을 지킬 방법을 설명하는 과학 탐구 콘텐츠입니다.

## 2. 대상

- 학년·학기: 초등 3학년 2학기(운영 시트 「이예리 선생님」 탭, 2026-11-22 확인)
- 과목: 과학
- 단원: 「지구와 바다」(운영 시트 단원명). 저장소의 교사 검토지(`docs/TEACHER-REVIEW-20261121.md`)에는 4학년으로 적혀 있어 대조가 필요합니다.
- 성취기준(`src/settingsContent.js`):
  - [4과06-01] 지구가 대기로 둘러싸여 있음을 알고, 지구 표면을 구성하는 육지와 바다의 특징을 비교할 수 있다.
  - [4과06-02] 바닷물의 특징을 육지의 물과 비교하고, 바닷가에서 볼 수 있는 다양한 지형을 조사할 수 있다.
  - [4과06-03] 밀물과 썰물의 차이를 알고, 갯벌의 가치와 보전의 필요성을 설득·홍보할 수 있다.
- 장별 연결: 1장 4과06-01, 2장·3장 4과06-02, 4장·5장 4과06-03. 문항 검수표는 `docs/TEACHER-REVIEW-20261121.md`입니다.

## 3. 준비

- 기기: 태블릿, 전자칠판, PC의 웹 브라우저. 3D 지구가 안 열리는 기기에는 설정의 「2D 지구 대체 화면 사용」이 있습니다.
- 소리: 배경 음악, 효과음, 목소리를 설정에서 따로 조절합니다. 글과 말풍선은 소리와 상관없이 나옵니다.
- 예상 시간: 「확인 필요」. 저장소에 수업 시간 기록이 없고, 성적표(`docs/reviews/SCORE-20261121.md`)에는 학생 40분 수업이 아직 확인되지 않은 항목으로 남아 있습니다.
- 이름·학번·연락처는 받지 않습니다.

## 4. 차시 흐름

시작 이야기(큰 파도 뒤 흩어진 기록) → 탐사 지도에서 시설 선택 → 장마다 네 화면(관찰·연결·도전·적용) → 최종 보고서 → 증거 연결 다섯 상황 → 엔딩 → 인증서

| 장 | 학생이 하는 일 | 배우는 개념 |
|---|---|---|
| 1 지구 관측소 | 푸른 지구를 돌려 보고, 내 표본과 지구 전체를 비교합니다 | 지구를 둘러싼 공기가 대기이며, 지구 표면에서는 바다가 육지보다 넓습니다. 몇 곳의 표본과 전체 넓이는 다릅니다 |
| 2 물 표본 실험실 | 육지의 물과 바닷물을 같은 조건에서 가열해 남은 물질을 비교합니다 | 증발이 일어나면 바닷물에 녹아 있던 소금 등이 남습니다 |
| 3 해안 조사구역 | 해안 네 지형을 사진에 담고 특징을 표시합니다 | 지형은 땅의 생김새이며 해안에는 모래사장·절벽·동굴 등이 있습니다 |
| 4 밀물·썰물 관측소 | 같은 장소의 시간별 기록에서 물 높이 변화를 비교합니다 | 물이 들어오며 높아지는 변화는 밀물, 빠지며 낮아지는 변화는 썰물입니다 |
| 5 갯벌 탐사구역 | 작은 흔적에서 생물을 찾고 갯벌을 지킬 근거를 정리합니다 | 갯벌은 여러 생물이 사는 곳이므로 생물과 사는 곳을 함께 지켜야 합니다 |

장마다 도전 두 문제와 새 상황 적용 두 문제가 이어집니다(전체 20문제). 정답 뒤에는 핵심 개념 카드가 나오고 다음 문제로 넘어갑니다. 4장 적용 문제 「물이 들어오면」은 3D 탐사길 걷기로 먼저 엽니다. 장을 마치면 탐사 도장을 받고, 지도에서 방해꾼(물때 교란 부표)을 물리치면 성취 카드를 받습니다.

## 5. 정답과 판정 기준

- 문제별 정답과 단서는 `docs/TEACHER-REVIEW-20261121.md`에 줄마다 있습니다. 틀려도 벌점은 없고, 단서를 보고 다시 고릅니다.
- 1장 예: 대기는 지구를 둘러싼 공기입니다. 표본이 육지뿐이어도 지구 전체 면적 자료와 구분해야 합니다.
- 2장 예: 실험 순서는 예상 → 같은 양 준비 → 같은 세기와 시간으로 가열 → 남은 물질 비교입니다.
- 3장 예: 단단한 바위가 높고 가파르게 서 있으면 절벽입니다. 위험한 곳은 안전한 길에서 보거나 사진 자료로 조사합니다.
- 4장 예: 06:00 낮음 → 12:00 높음 → 18:00 낮음 순서이고, 같은 바위가 더 많이 드러나면 썰물입니다.
- 5장 예: 거리를 두고 관찰하고 쓰레기를 되가져가는 것이 갯벌을 지키는 행동입니다.
- 마지막 증거 연결 다섯 상황은 각 장 기록과 연결된 이유를 고르며, 정답은 다음과 같습니다.
  - 지구 전체의 면적 자료와 내 표본은 구분해야 해
  - 바닷물에는 소금 등 녹아 있는 물질이 있어
  - 사진 속 재료와 모양을 보고 지형 이름을 연결해
  - 물이 들어오는 밀물의 변화야
  - 갯벌은 생물의 집이므로 흔적을 지키며 관찰해

## 6. 수업 팁

- 막히기 쉬운 곳: 1장에서 표본 몇 곳에 육지가 많다는 이유로 지구 전체도 육지가 넓다고 판단합니다. 표본과 전체 자료를 구분하게 합니다.
- 되묻기 좋은 질문:
  - 내 표본이 일부라면, 지구 전체를 말하려면 무엇이 더 필요할까요?
  - 두 물을 같은 양과 같은 조건으로 가열한 까닭은 무엇일까요?
  - 갯벌이 빈 땅이라고 말하는 친구에게 어떤 증거를 보여 줄까요?
- 전체 수업: 전자칠판에서 한 단계씩 함께 읽고 학생의 선택 근거를 먼저 물어봅니다. 서로 다른 답은 관찰 자료와 설명을 비교하는 토론으로 연결합니다.
- 모둠 수업: 카드는 끌어도 되고, 카드와 보관함을 차례로 눌러도 됩니다.
- 설정의 「교사용 도구」로 모든 단계를 한꺼번에 열 수 있습니다. 학생 기록은 만들지 않고, 다시 누르면 학생의 원래 진행으로 돌아갑니다.
- 안전: 실제 가열은 교사가 안전한 도구를 준비해 지도합니다. 화면의 물때 시각은 학습용이며 실제 물때와 다릅니다.

## 7. 저장과 다시 하기

- 진행과 기록은 이 브라우저의 `localStorage`(키 `blue-planet-hq:v2`)에 자동 저장됩니다. 서버로 보내지 않으며, 기기·주소·브라우저가 바뀌면 이어지지 않습니다.
- 처음부터 다시 하기: 설정 아래쪽 「탐사 기록 초기화」를 누르고 확인 창에서 「기록 지우기」를 누릅니다. 소리 설정은 남습니다. 공용 기기는 다른 학생에게 주기 전에 초기화합니다.
