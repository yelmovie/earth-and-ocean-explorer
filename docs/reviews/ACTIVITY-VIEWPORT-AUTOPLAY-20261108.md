# 활동 화면과 자동재생 수정 · 2026-11-08

## 적용 결과

- 20개 학습 화면을 상단 단계·활동·하단 조작 바로 구성했다. 관찰 장면은 남는 높이와 폭을 사용하며 다음 버튼은 별도 행에 둔다.
- 반복 안내, 카드마다 반복하던 미분류/미연결 문구, 중복 단서, 별도 시간 재생 버튼을 정리했다. 힌트·개념 영상·보충 설명은 도움말 하나로 모았다.
- 현재 할 일을 한 문장으로 표시하고 해당 조작 대상에 테두리를 준다. 선택지는 그룹 전체를 강조해 정답을 노출하지 않는다.
- 지구 관찰, 실험 조건 맞추기와 가열, 해안 촬영, 조석 관측과 비교, 생물 확대에 자동재생과 0.5·1·2·3배속을 제공한다. 예상·분류·특징·정답은 직접 선택한다.
- 가열 진행률과 물 높이는 같은 시간으로 계산한다. 일시정지/이어보기·속도 변경·화면 이탈·설정 열기·탭 숨김을 처리한다.
- 연속 질문은 한 항목씩 펼친다. 앞선 선택도 항목을 눌러 수정할 수 있다. 교사 이동 도구는 학습 화면에서 접어 둔다.
- 저장 형식과 기존 채점·보상 조건은 유지했다. 재생 상태는 현재 방문 동안만 보관한다.
