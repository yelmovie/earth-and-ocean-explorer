# 그림 교체와 화면 중복 정리 · 2026-11-17

## 기준으로 삼은 작업 방식

- Obsidian `30_SSD_프로젝트/30_과학34/과학34 공통 — 11월에 추가된 방식 2026-11-15`: 학생 흐름은 "지금 할 조작 → 바로 보이는 결과 → 다음 행동". 힌트는 정답을 말하지 않고, 개념 설명은 판단 뒤 복습으로 둔다.
- `edu-design` 불변 원칙: UI는 DOM/CSS, 그림은 이미지. 판정에 쓰는 도형과 값은 생성 그림으로 바꾸지 않는다. 같은 정보는 한 번만 보여 준다.

## 그림 교체 (Codex 내장 이미지 도구, 한 장씩 생성)

| 예전 | 지금 | 코드로 남긴 것 |
| --- | --- | --- |
| SVG 삼각형 바위, 사각형 기둥, 도형 배 | 투명 배경 바위·관측 기둥·나무 배 그림 | 물 높이 곡선, 기둥 눈금, 바위·기둥 이름표 |
| CSS 비커 테두리, 회색 막대 가열판, 점 소금 | 유리 비커·전기 가열판·소금 결정 그림 | 물의 양(%), mL 눈금 숫자 |
| SVG 지구(1장 설명판 문제) | 육지·바다·공기층 풍경 그림 | — |
| 아이콘 배지, CSS 원 인장 | 장마다 다른 메달 5장과 금색 인장 | 받은 배지·받지 않은 배지 구분(흐림) |

- 비커는 물과 눈금을 같은 안쪽 칸에 넣어 물 높이와 mL 눈금이 정확히 일치한다(40 mL → 눈금 40, 60 mL → 눈금 60을 브라우저에서 측정). 비커 칸은 그림 비율로 고정해 찌그러지지 않는다.
- 쓰지 않게 된 SVG 지구·절벽 그림 코드를 지웠다.
