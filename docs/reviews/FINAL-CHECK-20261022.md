## 실제로 고친 문제
- 학습 화면10→20, 장별8개씩 총40개 확장 문제를 추가하고 실제 완료 조건에 연결.
- 원문 성취기준과 관찰/비교/전이 활동을 매핑하고, 전체 면적 비율 암기·조석 원인 과잉을 피함.
- 새 섬·시설5종, 발자취 동행, 길 이동·카메라·복구 불빛 적용.
- 이름표 hover 때 위치가 튀어 클릭이 취소되던 공통 CSS 충돌 수정.
- 수면 SVG 숫자 사이 구분자 누락 수정.
- 불완전한 캐릭터 WebP를 복구하고 이미지 변환에 verify+임시 파일 교체 적용.
- 정적 빌드에서 CSS 변수의 상대 이미지 경로가 달라지던 문제를 document.baseURI 기준 URL로 수정.
- 개별 소리 모두 끔의 공통 아이콘, 이야기 창의 캐릭터 변수, 관리자 최종 콘텐츠의 실제 UI 진입점을 보완.
- 긴 활동의 확인/다음 행동을 태블릿 하단에 고정하고 모바일에서는 세로 스크롤 유지.

## 10점 기준선까지 남은 확인
1. 제공자와 납품 담당자가 기존 AI 이미지의 최초 생성·이용 조건을 납품 전에 확인한다. assets/CREDITS.md에 증빙을 연결한다.
2. 교사가 학생의 설명·오답 수정·보호 제안과 흥미를 관찰한다. 앱 완주를 성취기준 전체 달성이나 효과 검증으로 간주하지 않는다.
3. 실제 학교 태블릿·전자칠판에서 터치·글자·음량·회전,30기기 접속을 확인한다. 오프라인 새로고침 지원은 현재 MVP 범위 밖이며 학교 운영 조건에 명시한다.
