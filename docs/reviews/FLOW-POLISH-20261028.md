# 스테이지 조작 개선 — 2026-10-28

## 범위

기존 5장·20개 화면·확장 40문제의 반복 조작을 줄였다. 교육 정답, aReady/baseStageValid, 실제 증거·배지·해금·인증서 조건은 유지한다. 기존 에셋을 재사용했고 새 이미지·서버·외부 서비스를 추가하지 않았다.

## 변경

- 지구: 지점 선택과 스캔을 하나로 합쳤다. 기록마다 3D 지구를 다시 생성하지 않고 선택·수집 수·진행바·다음 단계 해금을 갱신한다. 이미 모은 지점을 눌러도 중복 저장하지 않는다.
- 표본: 첫 미분류 카드를 자동 선택하고 보관함에 넣으면 다음 미분류 카드가 준비된다. 직접 카드 선택, 수정, 터치 드래그는 유지한다.
- 실험: 학생이 직접 두 물의 양·세기를 맞추되 현재 어떤 조건이 다른지 즉시 안내한다. 화면 이탈·설정 변경 시 가열 타이머를 정리해서 복귀 후 다시 가열할 수 있다.
- 해안: 지형 표시를 누르면 사진을 바로 기록한다. 핀과 특징 연결은 서로 다른 학습 근거이므로 유지한다.
- 조석: 시간 재생이 마지막 시각에서 정지한다. 수동 조작과 탭 숨김에서도 정지하며, 현재 저장 시각의 중복 저장 버튼을 비활성화한다. 기준물·답 선택 후에도 비교선 위치를 유지한다.
- 갯벌: 특징을 고르면 즉시 검증·기록한다. 오답은 기록을 주지 않고 수정할 수 있다. 이전 버전에서 정답 특징만 선택한 미기록 저장도 이어서 기록할 수 있다.
- 확장 40문제: 단일 선택 즉시, 복수 선택·분류·연결·순서는 답 완성 시 기존 정답 함수로 검증한다. 다음 문제는 직접 넘겨 근거를 읽을 시간을 남긴다. 정답 경로의 추가 확인 40회와 카드 선택 47회를 줄였다. 이전 버전의 완성된 미확인 답에는 확인 버튼을 한 번 제공한다.
- 전환: 관찰→비교→도전→적용의 강제 영상 모달 15회를 없앴다. 영상은 언제든 선택 재생할 수 있다. 장을 마치면 짧은 배지 화면에서 다음 장 또는 지도로 이동한다.
- 피드백: 보이는 안내 영역 한 곳에서 전달하고, 숨겨진 안내만 있는 화면에서는 토스트를 사용한다. 중복 효과음을 줄이고 동작 줄이기 설정을 존중한다.

## 검증

- Node 단위 테스트 28개 통과. 자동 검증으로 40문제 해결, 오답 수정, 연타, 순서 되돌리기, 잘못된 드롭, 이전 저장, 증거 없는 배지 차단을 포함한다.
- 실제 Edge: 5장 관찰·비교·확장 40문제 → 최종 5상황 → 인증서 → 새로고침 완주 통과. 관리자 연습과 실제 기록 격리 확인, 콘솔 오류 0.
- 브라우저 조작 회귀: 지구 연타·키보드·새로고침, 표본 자동 선택·수정, 타임랩스 수동 개입·끝 정지, 비교선 유지, 가열 이탈·복귀, 촬영 중복 방지, 갯벌 오답 수정, 확장 문제 중복 입력 확인.
- 실제 Edge 4해상도(1280×800, 1280×720, 1024×768, 1920×1080) 224상태 통과. 가로 넘침·하단 버튼 이탈·작은 터치 영역 없음. 선택형 영상 5편, 실패 시 대체 그림, 동작 줄이기, Escape·이탈 정리도 확인했다. 콘솔·HTTP 오류 0.
- 갯벌 특징 3개가 펼쳐진 1280×720 화면의 높이를 조정하고 재확인했다. 이전 저장의 정답 특징 미기록 상태에서도 한 번 눌러 기록할 수 있음을 확인했다.
- 기존 로컬 글꼴 3개를 재생성했다. Bold 생성 중 시스템 메모리 부족이 발생해 별도 프로세스에서 재생성했으며, 원본·GSUB를 보존하고 전체 소스 한글 누락 0을 확인했다.
- `npm run build` 통과. 결과물은 `dist/`.

검증 산출물: `artifacts/browser-verification.json`, `artifacts/flow-polish/verification.json`, `artifacts/experience/verification.json`. 조작 개선 화면은 `artifacts/flow-polish/`, 전체 스테이지 모음은 `artifacts/experience/tablet-contact-sheet.jpg`.
