## 적용

- 확장 문제를 장마다 4개(도전 2·새 상황 적용 2), 총 20개로 정리했다. 비교 화면과 겹치거나 같은 개념을 반복하는 20개를 뺐다. 남은 문제는 장마다 성취기준 핵심 개념(대기·넓이 / 증발·같은 조건 / 지형 재료·안전 / 밀물·썰물·안전 / 생물 특징·보전)을 모두 다룬다.
- 새 상황 문제에 Codex 내장 이미지 도구로 생성한 장면 그림 9장을 붙였다(대기, 섬, 염전, 해안 재료, 해안 안전길, 새 절벽, 밀물 안전, 갯벌 보호, 갯벌 생물). 원본은 `assets/generated/20261116/`, 배포본은 `public/assets/illustrations/challenge-*.webp`.
- 정답 뒤 문제 카드 안에 노란 "핵심 개념" 카드를 띄우고, 약 3.2초(동작 줄이기 4.2초) 뒤 다음 문제나 적용 단계로 넘어간다. 버튼에 남은 시간이 띠로 보이고, 버튼을 누르면 바로 넘어간다. 화면의 다른 곳을 누르면 자동 넘김이 멈춘다. 배지 받기는 직접 누른다.
- 도움말에는 그 문제 고유의 단서를 보여 준다.
- 해안 비교: 사진을 누르면 오른쪽에 그 사진의 특징 버튼 4개가 크게 나오고, 고르면 다음 사진이 강조된다. 고른 특징은 사진 아래 칩으로 보이며 눌러서 다시 고를 수 있다. 네 장을 마치면 동굴·구멍 난 바위 비교 질문이 나온다.
- 실험 비교에서 "가열 전/후 확인" 표시를 없앴다(가열 완료가 두 확인을 함께 기록한다).
- 최종 미션: 증거와 이유를 모두 고르면 바로 확인하고, 맞으면 약 2.6초 뒤 남은 상황으로 이동한다.
- 자동재생 배속 선택은 재생 중에만 보인다. 제목·단계 설명을 둥근 반투명 카드에 올렸고, 낮은 화면과 폰에서는 납작하게 줄인다.
- 정답·해금·증거 저장 조건과 저장 키는 그대로다. 빠진 문제의 옛 저장 답은 불러올 때 무시되고, 이미 받은 배지·증거는 보존된다.
