# 캐릭터·관찰 일러스트 개선 — 2026-10-28

사용자가 요청한 이미지 생성 스킬을 적용해 CSS/Canvas로 단순화된 캐릭터와 관찰 그림을 교체했다.

## 적용

- 내장 image_gen으로 부리·짱이·게·짱뚱어·갈대 5종을 각각 단독 생성했다. 부리·짱이는 기존 캐릭터의 부리 모양·색·탐사복을 참고했다.
- 투명도와 모서리를 검사한 원본을 프로젝트에 보존했다. 실행 이미지는 WebP, 지도 부리는 별도 소형 WebP로 패키징했다. 홈에서는 439KB 시트 대신 약 150KB의 개별 캐릭터 두 장을 사용한다.
- 지도 부리의 사각형 그림 코드를 제거했다. 생성 이미지에 방향 전환·접지 그림자·걷기 반응을 연결하고, 이미지 실패 시 안내와 재시도를 제공한다.
- 홈·이야기 팝업·최종 연결·엔딩은 같은 개별 캐릭터 이미지를 공유한다. 말풍선·지도 안내 버튼이 캐릭터를 가리지 않도록 조정했다.
- 갯벌 관찰·도감·확장 활동·보고서의 게·짱뚱어·갈대는 공통 이미지 컴포넌트를 사용한다. 관찰 패널의 제목과 이미지를 한 행에 배치해 선택지와 겹치지 않도록 했다.
- 지구·실험·수위·면적 비율처럼 정확한 상태와 연결되는 과학 도해와 UI는 기존 코드로 표시한다.

## 검증

- Node 단위 검사 28개 통과.
- 실제 Edge에서 26개 경로 × 3개 해상도와 생물 선택 상태를 포함한 87개 상태 검사. 이미지 해독·가로 넘침·하단 버튼 위치 정상, 콘솔·HTTP 오류 0.
- 지도 실제 이동·복귀, 이미지 요청 실패 후 재시도, 이야기 팝업 두 캐릭터 표시를 확인했다.
- 기존 전체 활동 검사: 4개 해상도 224개 상태 통과. 터치 드롭·해안 쓸기·돋보기·영상 재생·실패 대체·동작 줄이기 포함, 오류·가로 넘침·긴 화면 없음.
- 저장된 생태 도감 팝업의 그림 3종과 지구 준비 완료 화면을 추가로 확인했다.
- 글꼴 3종을 새 문구로 재생성했다. 메모리 누적을 줄이기 위해 원본 파일명 인자로 각각 독립 실행할 수 있도록 했다.
- 최종 `npm run build` 통과. `dist/assets/illustrations/`에 신규 이미지 5종과 지도용 부리가 모두 포함된 것을 확인했다.

검증 근거: `artifacts/illustrations/verification.json`, `details-verification.json`, `all-pages.jpg`, `artifacts/experience/verification.json`.

실제 학교 태블릿·전자칠판 검증과 외부 배포는 수행하지 않았다.
