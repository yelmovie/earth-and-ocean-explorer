## 20활동 화면과 40문항

각 장은 관찰 `a`, 해석·기록 `b`, 확인 4문항 `c`, 적용 4문항 `d`로 구성된다. 활동에서 자료를 만든 뒤 분류·비교하고 새 상황에 설명을 옮기는 흐름이다. 확인·적용 문항의 정답 ID와 저장 구조는 유지했다.

| 장과 화면 | 관찰에서 기록까지 | 확인 4문항 | 적용 4문항 |
|---|---|---|---|
| 지구 관측소 `s1a`~`s1d` | 지구 회전·지점 스캔·대기 관찰 → 육지/바다 분류와 전체 넓이 모형 비교 | earth-sort, air-find, wide-sea, data-sort | island-new, sample-new, earth-words, earth-claim |
| 두 물 실험실 `s2a`~`s2d` | 예상 → 양·가열 조건 맞추기 → 전후 관찰 → 잔류물과 이유 비교 | fair-sort, lab-order, unequal-water, residue-look | unknown-water, heat-fix, lab-evidence, safe-lab |
| 해안 조사구역 `s3a`~`s3d` | 네 지형 사진 수집 → 특징 위치에 핀 → 재료·모양 설명 → 두 바위 비교 | coast-match, coast-material, cave-arch, field-order | new-cliff, wrong-signs, coast-safety, coast-claim |
| 물높이 관측소 `s4a`~`s4d` | 같은 장소의 여러 시각 → A/B 저장 → 같은 기둥·바위 비교 → 방향과 이름 | time-order, tide-match, incoming-proof, water-scenes | outgoing-proof, same-level, tide-safety, tide-model |

반복 선택으로 정답에 도달할 수 있는 문항이 있으므로 정답률만으로 이해를 판정하기는 어렵다. 교사용 가이드는 관찰 자료와 선택 이유를 설명하고 비교하도록 안내한다. 자동 관찰은 조작을 보조하며 예상·특징·분류·이유의 직접 선택은 학습자에게 남긴다. 최종 실행에서 이 경계를 확인한다.

## 새 물높이 판단과 옛 기록 보존

기존 수열 `[28,45,66,83,66,45,28]`에서 A=0, B=4는 마지막 높이가 처음보다 높지만 중간에 내려가기 시작한다. 수정 전에는 이 구간을 새 밀물 증거로 완료할 수 있었다. 반대 방향의 A=2, B=6도 같은 유형이다.

- `tideIntervalDirection`은 두 끝점과 모든 중간 기록의 높이 변화 방향을 비교한다.
- `recordTideObservation`은 순서·같은 높이·방향 전환을 검사한다. 거절할 때 초안을 바꾸지 않는다.
- A를 바꿔 기존 B가 부적합해지면 B와 기존 판단을 초기화한다. 같은 시각을 다시 저장할 때 현재 관찰을 보존한다.
- 새 완료 증거에는 단방향 조건을 적용한다. 과거 완료 증거의 정규화와 유효성 조건은 유지한다.
- 옛 구간 반전 초안으로 진행하려 하면 재관찰 안내를 제공한다. 이미 완료한 옛 증거는 재방문·새로고침 뒤에도 유지한다.
- 옛 증거의 화면 설명은 두 시각의 높이를 비교한 기록임을 밝히고 중간 변화도 살펴보도록 한다.

옛 완료 증거의 연구 문항이 비어 있으면 인증서가 실제0개를 표시한다. 옛 완료의 발급일과 연결 자격은 유지한다. 저장된 최종 답이 있으면 재진입 화면에서 그 답을 복원하고, 작성 중인 선택은 보존한다. 옛 해안 사진은 기존 이미지와 핀 위치를 함께 표시한다. 중간 방향이 바뀌는 옛 물높이 기록은 상세 화면과 요약에서 두 시각의 물높이 비교로 안내한다.

### 검증 환경과 범위

macOS Chrome의 터치·뷰포트·네트워크 모사를 사용했다. 개발 서버 갱신 때문에 중단된 초기 자동관찰·저장 검사는 HMR 없는 검증 서버와 최종 프로덕션 빌드에서 다시 실행해 통과했다. 이미지 최초 캡처에서 로딩 전 빈 영역이 있어 디코딩을 기다린 화면을 추가로 직접 확인했다. 검사 종료 후 단순 성공 로그만으로 시각 판정을 대신하지 않았다.
