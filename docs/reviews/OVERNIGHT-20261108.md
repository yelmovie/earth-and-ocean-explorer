# 지구와 바다 야간 고도화 검토 · 2026-11-08

## 변경 범위와 결정

실물 관측처럼 느껴지는 조석 해안 배경 1장을 제작했다. 기존 해안 사진·생물 그림은 이미 상세하여 불필요하게 교체하지 않았다. 이번 범위는 폴더 `10 earthsea`이며 시트의 여섯 번째 단원이다. 기존 미커밋 변경, 한 화면 활동 구성, 재생 속도 선택, 관측 자동 진행과 수동 정답 선택을 보존했다. 배포·커밋·새 의존성 설치는 하지 않았다.

- `src/screens.js`: 조석 관측·A/B 비교의 단순 도형 해안 바탕을 생성 이미지로 교체. 수면, 기둥, 바위, 배, 글자는 SVG로 유지했다. 일곱 시각의 수면 높이도 변경하지 않았다.
- `src/challenges.js`: 조석 확장 문제의 배경도 같은 이미지로 통일. 기존 상승·하강·같은 높이와 시간순서 자료는 그대로 유지했다.
- `public/assets/tide-foreshore.webp`: 실행용 해안 배경.
- `public/assets/tide-foreshore-manifest.json`, `public/assets/CREDITS.md`: 원본·생성 도구·사용처·권리 검토 고지.
- `src/responsive-stages.css`: 세 시각 도해의 그림을 70px 시간 열 옆에 끼워 넣던 기존 CSS 충돌을 수정해 시간 아래에 충분한 크기로 표시했다. 조석 관측 그림의 불필요한 상하 여백을 제거했다. 한 화면 구성은 유지했다.
- `tests/tide-visual.test.js`: 정적 배경과 동적 과학 모형을 분리하는 회귀 검증 2건.
- 자체 `graphify-out`만 갱신했다. 공동 루트 그래프는 변경하지 않았다.

## 이미지 제작과 검수

실제 생성 도구는 내장 OpenAI `image_gen`이다. Imagen 사용 결과가 아니다. 원본: `assets/generated/20261108/tide-foreshore-original.png`. 한 이미지에 한 배경만 제작했고 글자·UI·물·기둥·배를 넣지 않았다. 중성 낮빛의 초등 교육용 2D 해안 그림이다. 원본의 실제 픽셀에서 물이 없는 모래 전경과 낮은 초지 배경을 확인했다. 배경은 본래 불투명이며 투명 오브젝트를 흰 바탕으로 대체한 것이 아니다.

기둥과 바위를 배경에 굽지 않아 두 기록의 고정 기준물이 정확히 일치한다. 바닷물은 기존 좌표와 높이 함수가 그리므로 그림 속의 고정 수면이 관측 수면과 충돌하지 않는다. UI 글자나 선택지를 이미지에 넣지 않았다. 브라우저 기본 WebP 인코더로 사용본을 만들고 원본은 보존한다.

## 학습 설계와 과학 범위

현재 5장 × 4화면, 확장 40문항의 분량을 유지한다. 단순히 문제를 더 늘리지 않았다. 조석 활동은 시간 관측 → 다른 높이의 두 기록 → 같은 기둥·바위 비교 → 변화 방향·밀물/썰물 설명 흐름이다. 자동 진행은 관측을 도울 뿐 정답을 대신 고르지 않는다.

교육과정 근거는 프로젝트 PRD와 상위 검토에서 대조한 경기도교육청 2022 개정 교육과정 과학 원문(인쇄 85쪽)이다.
https://www.goe.go.kr/resource/old/BBSMSTR_000000030136/BBS_202411110127574203.pdf

이 변경에서 조석의 원인·달의 인력·실제 조석 예보를 추가하지 않았다. 해안 침식·운반·퇴적 과정을 평가하지 않는다. 바닷물의 양·원리 변경, 기기별 CSS 재설계, 완료·해금 구조 변경도 하지 않았다.

## 최종 학생 용어 정리

교육과정 범위에 맞춰 학생에게 보이는 시설 이름을 ‘밀물·썰물 관측소’로 통일했다. src/data.js의 공통 이름, src/screens.js의 도움말, src/concepts.js의 개념 영상 자막에서 ‘조석’을 ‘밀물·썰물’로 바꾸었다. 내부 ID·이미지·수면 로직·과거 문서는 변경하지 않았다. src와 현재 자산 JSON에서 남은 ‘조석’ 문구가 없음을 검색했다.

문구 변경 후 단위 테스트 45/45, 프로덕션 빌드 통과. 915×412, 375×812, 768×1024의 4장 전체 활동/문제 상태 30건에서 잘림·겹침·조작 대상·패널 경계 검사 모두 통과했고 오류 0건이었다. 낮은 가로/휴대폰 세로 화면 스크린샷을 직접 열어 늘어난 제목도 확인했다. 결과는 output/overnight-20261108/terminology-*.log와 terminology-viewport/에 남겼다. 이 검증도 상태 주입 레이아웃 검사이며 별도 전체 완주를 의미하지 않는다.
