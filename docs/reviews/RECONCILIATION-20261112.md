## 발견과 복구

공개 `assets/CREDITS.md`는 6,108바이트의 구형 사본이었다. 최신 글꼴, 15초 개념 영상, 캐릭터 음성39개, 공개 배포 상태가 반영되지 않았다. 저장소 쪽 `assets/CREDITS.md`에는 공개 사본에만 있던 Canva 홈 배경과 밀물·썰물 관측 배경의 출처가 빠져 있었다.

두 사본의 출처를 합쳐 같은 내용으로 복구했다. 생성 계정·이용권 증빙의 확인 조건도 보존했다. 최신 파일은7,145바이트이며 SHA-256은 `25f247a7b33a3c92abdea759aa96eb48304f4946fb5de9359e9152d6a2a04bed`다.

`tests/release-assets.test.js`를 추가해 두 고지 사본이 달라지면 CI가 실패하게 했다. 단위 테스트59개와 프로덕션 빌드가 통과했다. `HANDOFF.md`의 최신 납품 기록을 맨 위로 옮겨 과거의 미배포 안내와 현재 상태를 구분했다.

추가 스크린샷 검토에서375px 허브의 미션 안내가 상단 아이콘 뒤에 겹치고, 음성 정지 버튼을 포함하면18px 가로 넘침이 발생했다. 좁은 화면의 미션과 사진 작업대를 상단 도구 아래 흐름으로 배치했다. 사진 작업 중에는 미션 안내를 접고, 작업대를 접으면 미션 안내를 다시 표시한다. 짧은 가로 화면에서는 사진 작업대 안에서 스크롤해 지도 이동 조작부를 확보한다.

지도 이름표는 화면 안쪽으로 이동한 실제 좌표와 폭으로 미션·사진 영역을 피하게 했다. 다른 이름표를 피해서 옆으로 이동하는 후보 위치도 같은 기준을 사용한다. `tests/hub-overlay-browser.mjs`를 추가했고, 수정 전 공개본 실패와 수정 후 실제 개발 앱의39상태 통과를 각각 보존했다. 초기·일부 완료·전체 완료·교사 시연, 사진 열기/닫기, 전체 지도와 좌우 이동을375×812·915×412·1024×768에서 검사했다.

통합 빌드 미리보기에서도 허브39상태를 다시 통과했다. 같은 빌드에서 상태 주입 없이20활동·40확장 문항·5최종 문항·인증서까지 완주하고 중간 새로고침·최초 예상·교사 기록 분리·초기화 취소·인쇄 한 장을 확인했다. 결과는 `reconcile-preview-hub/`와 `reconcile-preview-journey/`에 있다.
