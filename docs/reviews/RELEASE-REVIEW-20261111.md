- `npm test` 58개 통과, `npm run build` 통과.
- 빌드 미리보기에서 실제 클릭·슬라이더 키보드 조절·분류·선택으로 20활동, 확장40문항, 최종5문항, 인증서까지 완주했다. 진행 상태 주입 없이 검증했다.

### 성능·미디어

- 최종 로컬 빌드에서 냉 캐시 첫 화면과 웹폰트 준비는 일반1.294초, 10Mbps·80ms RTT 모사1.814초였다. 전송량은2,046,870바이트다.
- 탐사 지도에서120프레임 표본의 중앙값16.7ms, 95백분위16.7ms를 측정했다. 학교 태블릿 FPS는 별도다.
- 개념 영상5편이1280×720으로 디코딩되고15초 재생·4개 장면·음소거 연동이 동작한다. 음성39개가 HTTP성공 및 오디오 디코딩을 통과했다.
- 첫 화면에 뒤 스테이지 지도·3D 지구·전체 영상을 내려받지 않는다. 런타임 요청은 현재 origin 내부에서 발생한다.
- 오프라인 새로고침은 지원하지 않는다. 현재 전체 public 자산은18,538,591바이트이며, 가장 큰 영상은약1.74MB다.
