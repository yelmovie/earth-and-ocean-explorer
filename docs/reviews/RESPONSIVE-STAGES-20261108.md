# 스테이지 반응형·관찰 자료 개선 · 2026-11-08

5개 장의 관찰·비교 10화면과 도전·적용 40문제를 개선했다. 자동 화면 검사 450상태, 생태 그림 보완 후 추가 검사 72상태에서 감지한 잘림·겹침·가림·가로 넘침은 0건이다. 단위 테스트 43개와 전체 탐사 흐름, 주요 터치·미디어 조작, 최종 빌드가 통과했다.

## 배치와 가독성

- 선택지의 체크·번호·문장·보조 아이콘을 별도 칸으로 나눴다. 긴 문장은 높이가 늘어나며 줄바꿈한다.
- 제목과 단계 탭은 1200px 이하에서 별도 행, 학습 패널은 900px 이하에서 한 열로 전환한다.
- 진행 버튼과 교사 이동 도구를 문서 흐름에 배치해 슬라이더·설명·선택지를 덮지 않는다. 작은 화면에서는 자연 스크롤로 모든 조작에 도달한다.
- 좁은 화면에서 분류함 제목과 연결 개수가 서로 밀어내지 않도록 각각 별도 행으로 배치했다.
- 휴대폰에서 세로 flex에 남은 가로 기준 flex-basis가 진행 영역의 높이를 부풀리던 문제를 제거했다.
- 새 임시·브라우저 파일이 Git에 섞이지 않도록 `.tmp/`를 제외했다.

저장 형식·정답 데이터·완료 조건·기록 보호·미리보기 격리 로직은 이번 작업에서 변경하지 않았다. 기존 작업 내용과 에셋을 보존했으며 새 의존성·다운로드·생성 미디어는 추가하지 않았다.

## 검증 근거

환경: macOS Google Chrome 헤드리스, 기존 외장 SSD의 Python Playwright. 브라우저 프로필·임시파일·npm 캐시·빌드·스크린샷·로그는 USB 외장 T7 Shield에 저장했다. 실제 외장 장치·쓰기 가능·여유 공간을 작업 전에 확인했다.

화면 검사 크기: 1920×1080, 1366×768, 1280×800, 1024×768, 1024×600, 915×412, 830×515, 768×1024, 375×812. 1개 크기마다 관찰·비교 10상태 + 도전·적용 40상태를 검사한다. 전체 스윕의 지구는 2D 관찰 설정이며, 기본 3D 경로는 정상 탐사 흐름 검사로 확인했다.

검사 항목은 가로 넘침, 48px 터치 영역, 버튼 텍스트의 Range 경계, 선택 아이콘과 문장 겹침, 비커 눈금 겹침, 갯벌 설명 간 겹침, 화면 안 컨트롤의 실제 중심점 가림, 다음 버튼 스크롤 도달, 과도한 진행 영역 높이, 생물 그림과 이름표 겹침이다. 스크롤로 도달 가능한 내용을 화면 밖 오류로 판정하지 않는다. 흔적 이름표는 의도적으로 원형 버튼 밖에 있어 버튼 내부 글자 검사에서 제외하되 이름표 간 겹침은 별도로 검사한다.

상호작용 검사 구간은 Pillow가 필요한 접촉 시트·기존 레이아웃 스윕 구간 앞까지 실행했다. 해당 구간을 실행한 것으로 보고하지 않으며, 레이아웃은 새 전수 검사기로 확인했다.
