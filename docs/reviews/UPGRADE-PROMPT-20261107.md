# 10 earthsea 실제 적용 개선 프롬프트

대상: 푸른행성 조사본부. SSD 10번은 운영 시트의 번호와 다를 수 있으므로 이름으로 대조한다. 1~5번과 다른 프로젝트는 수정하지 않는다. 기존 5개 장, 40개 확장 과제, 픽셀 탐사지도, 그림/영상/음원을 보존한다. 커밋·배포·개인정보 수집 없이 아래를 적용한다.

1. 물 실험의 처음 예상을 최초 선택 시 보존하고 이후 예상과 구분하라. 이전 기록에 최초 값이 없으면 만들어내지 말고 최초 여부 미확인으로 표시한다. 재탐구를 완료해도 최초 증거 스냅숏을 덮어쓰지 않는다.
2. 저장을 읽은 상태마다 원본 문자열을 추적한다. 손상/미지원 미래 형식/다른 탭의 갱신이 있으면 자동 덮어쓰기를 중지하고 학생에게 알린다. 명시적인 초기화 확인만 보호를 해제한다. 저장 불가에서도 임시 탐구는 허용한다.
3. 교사 전체 해금은 학생 상태의 복사본으로 체험하게 한다. 이동/선택/완료/초기화가 학생 기록에 저장되지 않아야 한다. 종료하면 학생 상태·라우트로 복원하고 미리보기 인증서를 인쇄하지 않는다. 기존 unlockAll 저장도 안전하게 취급한다.
4. 915×412처럼 낮은 화면과 작은 세로 화면에서 고정 풋터와 교사 도구가 활동을 덮지 않게 자연 스크롤을 허용한다. 교사 방향키도 최소 48×48px로 한다. 본문을 과도하게 줄이지 않는다. 3D 지구 DPR은 최대 1.5로 제한한다.
5. 반례 테스트를 먼저 실패시킨 뒤 수정한다. 정상 5단원/40과제/최종 연결/인증서/재접속, 두 탭 충돌, 손상 보존, 교사 격리, 8개 뷰포트와 기존 미디어/터치를 검증한다. 검사기 판정 외에 화면을 눈으로 확인한다.

## 실제 적용
src/state.js, main.js, screens.js, globe.js, experience.css에 적용했다. 기존 검사기를 Mac/Windows 공용 실행 경로와 별도 결과 폴더를 지원하도록 확장했다. tests/safety_browser.py, compact_browser.py 및 단위 회귀 6개를 추가했다. 신규 생성 이미지·음원은 만들지 않았으며 기존 풍부한 자산을 재사용했다.
