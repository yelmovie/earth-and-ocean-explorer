# 개념영상 SPEC · 「모아의 탐사 노트」 (2026-11-09)

6번 A안 "실험 노트"를 이 게임 말로 옮겼다: 질문 → 방금 한 활동 재현 → 바뀐 곳 확대 + 이름표 → 결론 한 줄 → 모아 반응. 한 편에 한 생각.

```text
GOAL:    활동을 마친 아이가 영상 한 번으로 "그래서 ~구나"를 한 문장으로 말한다.
OUTPUT:  HyperFrames 0.9.26, 1920×1080 30 fps 원본(TMPDIR) → 앱 1280×720 H.264+AAC mp4(faststart) / VP9+Opus webm, 마지막 장면 WebP 포스터
TIME:    편당 15 s(450 frames). 장면 경계 0 / 3.5 / 8 / 11.5 s = 앱 자막·장면 버튼(src/concept-data.js)과 같음
LOOK:    바탕 = 게임 배경 그림 그대로(관측소·실험실·해안·밀물썰물 해안·갯벌). 잉크 #173f4b, 종이 #fffdf5/#fbf6e6,
         강조 #b26a00(결론 한 낱말만), 바다 #379eaf, 육지 #9ebf75, 핀 #efbd6e. 글꼴 Jua(OFL, assets/fonts).
         이름표 44 px(보조 30 px), 질문 52 px, 결론 68 px. 그림자 0 10px 18px rgba(23,63,75,.2).
OBJECTS: 모아(게임 안내 수달), 게·짱뚱어·갈대(게임 도감 그림), 지도(public/assets/land.geojson), 비커·가열판(게임 실험 화면 모양),
         기둥·바위·배·물(src/screens.js tideScene 좌표 ×4). 해안 지형 위치는 src/data.js terrains 좌표.
MOTION:  모아 등장 expo.out 0.7 s + 찌그러짐 0.12 s → back.out 0.3 s. 질문은 낱말마다 blur 6→0(0.14 s, 0.09 s 간격).
         이름표 = 지시선 0.22 s 먼저 → 카드 back.out 0.32 s. 카메라 이동 power2.inOut 0.55~0.8 s. 결론 blur 8→0 0.4 s 후 고정.
         모아 반응 = 웅크림 → 뛰어오름 → 착지 찌그러짐 → 고개 갸웃(12.0~14.1 s).
SOUND:   음악 없음. 행동마다 Kenney CC0 효과음 하나(핀 떨어짐 drop, 가열 heat, 촬영 camera, 이름표 scan, 결론 success).
         앱에서는 전체 음소거·효과음 끔 설정이면 video.muted.
BANNED:  어두운 바탕·네온·빛번짐·떠다니는 입자, 보라/파랑 그라데이션, 글래스 카드, 01/02 번호, 카드 세 장 나란히,
         모두 동시 페이드업, 읽는 동안 움직이는 글자, 입자(분자) 모형, 밀물·썰물 원인(달) 설명, 실제 조석 시각처럼 보이는 표현.
```

| 편 | 0–3.5 질문 | 3.5–8 관찰 | 8–11.5 확대 | 11.5–15 정리 |
|---|---|---|---|---|
| 1 지구 표면 | 지도 펼쳐짐, 육지·바다 이름표 | 핀 4개(육지 3·바다 1) + "내 표본" 카드 | 표본 카드에 줄 긋기, 지도 흐려지고 10칸 띠(바다 7·육지 3) | 전체 넓이는 **바다**가 더 넓어 |
