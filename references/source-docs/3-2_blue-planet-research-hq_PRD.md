# PRD — 푸른행성 조사본부

- **Project:** 아이스크림미디어 Science World
- **Title:** 푸른행성 조사본부
- **English working title:** Blue Planet Research HQ
- **Repository:** `blue-planet-research-hq`
- **GitHub Description:** `Interactive Grade 3 science game for investigating Earth's surface, seawater, coastal landforms, tides, and mudflat ecosystems through observation, experiments, time-based comparison, and evidence-based missions.`
- **대상:** 초등학교 3학년
- **교과/학기:** 과학 3학년 2학기 「지구와 바다」
- **교육과정 기준:** 2025학년도 적용 2022 개정 교육과정
- **구조:** 정확히 5 Stages / 총 10 Screens
- **형식:** 태블릿 우선 웹, 16:9 가로형, 데스크톱 호환
- **핵심 엔진:** Phaser 3 + Three.js + HTML/CSS/SVG
- **저장:** 백엔드 필수 없음, IndexedDB 우선 + localStorage 폴백
- **3D:** Screen 01·02·03·10. Screen 03은 핵심 학습 3D, 01·02·10은 경량 허브/엔딩 3D
- **문서 버전:** 1.0
- **작성일:** 2026-08-25

## 1. 제품 한 줄 정의

「푸른행성 조사본부」는 학생이 지구와 바다 관련 정답을 고르는 디지털 문제집이 아니라, **3D 지구 관측 → 표본 비교 → 물 표본 실험 → 해안 현장 조사 → 시간축 밀물·썰물 비교 → 갯벌 생태 증거 수집 → 근거 기반 보호 브리핑**을 수행하는 초등 3학년 과학 조사 게임이다.

---

## 2. 제품 목표

핵심 학습 루프:

**조사 계획 또는 예상 → 직접 조작 → 관찰 → 증거 기록 → 비교 → 판단 → 적용/설득 → 재검토**

이 제품은 “왜 굳이 태블릿으로 해야 하나?”에 다음 기능으로 답해야 한다.

1. 3D 지구를 직접 회전·확대하며 대기·육지·바다를 관측한다.
2. 학생이 수집한 표본이 다음 화면의 비교 자료가 된다.
3. 두 물의 조건을 직접 맞추고 가열 전후를 반복 비교한다.
4. 해안 현장을 이동·촬영하고 지형의 특징을 사진 위에 표시한다.
5. 밀물·썰물을 영상 시청으로 끝내지 않고 시간축을 앞뒤로 움직여 같은 장소의 두 시점을 비교한다.
6. 갯벌 생물을 이름부터 제시하지 않고 흔적→확대→특징→후보 비교 순으로 조사한다.
7. 최종 화면에서 앞에서 모은 실제 조사 증거로 갯벌 보호 필요성을 설득·홍보한다.
8. 동일한 드래그앤드롭을 반복하지 않고 Stage별 핵심 조작 문법을 바꾼다.

## 3. 교육과정 근거

### 직접 성취기준

**[4과06-01]** 지구가 대기로 둘러싸여 있음을 알고, 지구 표면을 구성하는 육지와 바다의 특징을 비교할 수 있다.

**[4과06-02]** 바닷물의 특징을 육지의 물과 비교하고, 바닷가에서 볼 수 있는 다양한 지형을 조사할 수 있다.

**[4과06-03]** 밀물과 썰물의 차이를 알고, 갯벌의 가치와 보전의 필요성을 설득·홍보할 수 있다.

### 성취기준 → 수행 행동

| 성취기준 | 게임에서 확인할 수행 행동 |
|---|---|
| [4과06-01] | 3D 지구에서 대기·육지·바다 관찰, 여러 지점 스캔, 육지/바다 자료 비교, 조사 결과를 근거로 결론 |
| [4과06-02] | 육지의 물/바닷물 동일 조건 비교, 가열 뒤 결과 확대 관찰, 바닷가 지형 촬영·특징 표시 |
| [4과06-03] | 동일 해안의 시간 변화 비교, 변화 증거 표시, 갯벌 생물 특징 조사, 갯벌 가치 증거를 사용한 보호 브리핑 |

## 4. 과학 내용 가드레일

- 밀물·썰물은 바닷물 높이와 해안에서 드러나고 잠기는 모습의 차이 수준으로 다룬다.
- 달의 인력, 조석 발생 원인, 조석 주기 계산을 핵심 학습·평가로 넣지 않는다.
- 바닷가 지형은 모습과 특징 조사에 집중한다.
- 침식·운반·퇴적의 세부 원인 분석을 본 단원 핵심 평가로 삼지 않는다.
- 바닷물을 가열하고 남는 물질을 순수한 소금 하나로 단정하지 않고 “흰색 고체 물질”, “소금 등 바닷물에 녹아 있던 물질” 수준으로 표현한다.
- 바닷물이나 남은 물질을 직접 맛보는 상호작용을 넣지 않는다.
- 실제 조석 시각 예측·해수 성분 정량 분석 기능으로 오해되는 UI를 넣지 않는다.
- 갯벌 생물 이름만 맞히면 통과하는 구조를 금지한다.

---

## 5. 첨부 수업자료 벤치마킹 원칙

첨부 자료는 **학습 구조와 기능 아이디어만 참고**한다. 캐릭터, 문항, 화면, 문구, 점수 규칙, 게임 룰은 복제하지 않는다.

- 대기/공기 선택 게임 → **3D 대기 렌즈와 다방향 관찰**로 변환
- 육지/바다 넓이 비교 → **학생이 직접 수집한 표본의 누적 비교**로 변환
- 육지의 물/바닷물 OX·카드 → **동일 조건 가상 실험 + 전후 비교**로 변환
- 바닷가 지형 퍼즐 → **현장 이동 + 촬영 + 특징 마킹**으로 변환
- 밀물·썰물 사진/타임랩스 → **Timeline Scrubber + A/B Snapshot**으로 변환
- 갯벌 순간카메라 → **흔적→확대→특징 2개→후보 비교→도감 등록**으로 변환
- 갯벌 홍보자료 만들기 → **자신의 조사 증거를 이용한 주장-근거-실천 브리핑**으로 변환

## 6. 대상 사용자와 난이도

### 학생
- 초등학교 3학년
- 설명은 짧고 명확하게, 사고 단계는 낮추지 않는다.
- 한 번 누르면 끝나는 활동보다 관찰→근거 표시→판단 구조를 사용한다.

### 금지
- OX 연속
- 2~4지선다만으로 Stage 완료
- 같은 그림끼리 단순 끌어놓기 반복
- 영상 시청 후 정답 버튼
- 실패 즉시 정답 공개
- 긴 설명문 독해가 진행의 핵심인 구조
- 중등 수준 조석 원인/계산

## 7. 세계관

Science World 포털 안의 **푸른행성 조사본부**에서 관측망 오류가 발생해 다섯 데이터가 손상되었다.

1. 지구 표면 데이터
2. 물 표본 데이터
3. 해안 지형 데이터
4. 바닷물 변화 데이터
5. 갯벌 생태 데이터

학생은 신입 조사원이 되어 장비를 직접 사용해 증거를 확보하고 데이터베이스를 복구한다.

자연현상을 기계가 만들어 낸다는 설정은 사용하지 않는다. 학생은 자연을 조종하는 사람이 아니라 **관측·실험·조사하는 사람**이다.

## 9. 화면별 핵심 설계

### SCREEN 01 — 조사본부에 접속하라
- Three.js 경량 3D
- 푸른 지구와 5개 오류 신호
- 지구 제한 회전, 오류 raycast
- 오류 신호 3개 이상 확인 후 조사 시작
- 학습 평가보다 역할·맥락 형성
- 자유 비행/우주전투 연출 금지

### SCREEN 02 — 다섯 조사 데이터를 확인하라
- Three.js + DOM
- 5개 데이터 코어: LOST → RESTORED
- Stage 진입, 조사노트, 진행도
- 기본 순차 해금, 교사용 해금 시 자유 이동
- Screen 10에서 동일 HQ scene 재사용

### SCREEN 03 — 지구를 스캔하라
- [4과06-01], 핵심 Three.js
- 지구 회전, pinch zoom 보조, 대기 렌즈, 지표 스캔
- 대기 관찰 3방향 이상
- 육지/바다 표본 8개 이상 수집
- 한쪽 지역만 반복 조사되지 않게 coverage rule
- 수집 표본은 Screen 04로 전달

### SCREEN 04 — 표본으로 비교하라
- [4과06-01], DOM/SVG
- 학생이 모은 표본 검토·분류
- SVG 비교 그래프
- 근거 2개 이상을 보고 결론
- “바다가 더 넓다”를 시작부터 알려주지 않음
- 오분류 시 원본 표본 재관찰

### SCREEN 05 — 두 물의 흔적을 비교하라
- [4과06-02], Phaser + DOM
- A/B 물 표본의 양을 같게 맞추기
- 가열, 시간 진행, 확대 관찰, 전후 스냅
- 동일 조건이 아니면 실험 진행 잠금
- 바닷물 쪽에 흰색 고체 흔적 표현
- 결과를 순수 소금 하나로 정량 단정하지 않음
- 맛보기 금지
- 두 접시의 전후 근거 2개 이상 필요

### SCREEN 06 — 해안을 조사하라
- [4과06-02], Phaser 2.5D
- 해안을 좌우로 이동
- 모래사장, 절벽, 동굴/움푹 들어간 바위, 구멍 난 바위, 갯벌 등 검수된 지형
- 이름을 먼저 보여주지 않음
- 촬영 + 특징 2곳 이상 마킹
- 서로 다른 지형 4종 이상 조사
- 형성 원인 심화 평가 금지

### SCREEN 07 — 해안 기록을 완성하라
- [4과06-02], DOM/SVG/Canvas
- Screen 06에서 찍은 사진·특징을 그대로 사용
- 사진→특징→지형 이름 연결
- 비슷한 두 지형 1쌍 비교
- 잘못 연결하면 원본 현장으로 돌아가 재관찰
- 개인 해안 조사 앨범 완성

### SCREEN 08 — 시간을 움직여 비교하라
- [4과06-03], Phaser 2.5D
- Timeline Scrubber로 같은 해안의 시간 변화 조작
- A 시점 저장, B 시점 저장
- 분할 비교
- 길·배·바위·기둥·해변 경계 등 변화 지점 2개 이상 표시
- 바닷물 높이 변화 판단 후 밀물/썰물 용어 연결
- 실제 조석 예보·달의 인력 설명 없음

### SCREEN 09 — 갯벌의 단서를 수집하라
- [4과06-03], Phaser + DOM
- 구멍·흔적·식물 일부·움직임을 먼저 발견
- 확대경, 생태 스캐너, 사진, 특징 핀
- 게, 조개, 망둑어/짱뚱어, 갯지렁이, 철새, 나문재, 퉁퉁마디, 칠면초 중 검수된 세트
- 사진/관찰 스냅 + 특징 2개 이상이어야 도감 등록
- 동물/식물/철새를 포함한 최소 5개 조사
- 가치 근거 카드도 함께 확보

### SCREEN 10 — 최종 보호 브리핑
- [4과06-03], Three.js 경량 3D + DOM
- Screen 02의 HQ scene 재사용, 모든 코어 복구
- 주장 + 학생 조사 증거 2개 + 갯벌 가치 근거 1개 + 실천 제안 1개
- 선택적 10초 음성 브리핑
- 음성 권한 없이도 완주 가능
- 선택적 PNG 결과 카드
- BLUE PLANET DATA 100%
- 푸른행성 조사원 배지

- 3D 내부 한글 text mesh 금지
- 자유 비행 금지
- 저사양 태블릿 3D 최소 30fps 목표

## 11. 상호작용 다양성

제한 3D 회전, pinch zoom, 대기 렌즈, raycast 스캔, 표본 분류, SVG 그래프, 스포이트 양 조절, 가열, 시간 진행, 확대경, 전후 스냅, 2.5D 이동, 카메라 촬영, 특징 마킹, A/B 비교, timeline scrub, evidence pin, 흔적 탐색, 생태 스캐너, 후보 비교, 주장-증거 연결, 짧은 문장 작성, 선택적 음성, PNG 결과 카드.

규칙:
- 동일 drag-and-drop만으로 연속 Stage를 완료하지 않는다.
- 각 Stage에 학생이 직접 만드는 관찰 증거가 최소 1개 있다.
- 학생 기록이 다음 판단에 실제로 사용된다.

## 12. 피드백·힌트

잘못된 방식:
- “틀렸습니다.”
- 빨간 X만 표시
- 정답 자동 이동
- 정답 문장 즉시 공개

권장:
- “한쪽 지역만 조사했어. 지구를 더 돌려볼까?”
- “두 표본의 양이 달라. 비교 조건을 먼저 맞춰 봐.”
- “이름보다 네가 표시한 사진 특징을 다시 확인해 봐.”
- “A와 B에서 길이 보이는 정도가 어떻게 달라졌지?”
- “생물 이름을 정하기 전에 특징을 하나 더 찾아봐.”
